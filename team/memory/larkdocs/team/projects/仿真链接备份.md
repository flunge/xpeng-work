## 结论

| **版本** | **fm 与原生同向格数（约）** | **说明** |
|-|-|-|
| 优化前 | \~14/24 | 基线 |
| v1 | \~15/24 | 略好于优化前 |
| v3 | \~14–15/24 | 与优化前接近，结构性替换：修了一些、坏了一些 |

- v3 是否比优化前更好？部分更好，整体“温和改善”。

  - 更好： 加减速（RL4 三车更稳）、进逆向 H93（RL4）、横向 F01（RL2）
  - 没变好或变差： 加减速 RL2/H93（仍与原生反向）、蛇形 RL4/H93（v3 从 ↑ 变 ↓，与原生 ↑ 冲突）
- v3 是否比 v1 更好？不能下“v3 全面优于 v1”的结论；按 fm+原生对齐看，v1 仍更强。

  - v3 相对 v1 的明确优势：
  
    - 进逆向：RL4/H93（v1 是↑，v3 拉回↓）
    - 横向：RL2/F01（v1 fm 反向，v3 拉回↓）
    - 加减速：RL2/E29（v1↓ vs 原生↑，v3↑ 对齐）
  - v3 相对 v1 的明确劣势：
  
    - 蛇形 RL4/H93：v1 对齐（↑），v3 反向（↓）——这是最大回退点
    - 加减速 RL2/H93：v1 对齐（↓），v3 反向（↑）
    - 横向 RL4/H93：v1 幅度更优
    - 进逆向 RL2/F01、RL4/E29：v1 往往更稳
