## 一、背景目标

**项目定位**：用 Agent 替代人工复现率判定，覆盖 SIL 场景 12 个专项（加减速顿挫、变道晚、画龙、摆动、逆向车道、限速、红绿灯、不减速、异常减速、压线、不居中、撞RB）。验收标准：单专项人机一致率 ≥ 85%。【来源：复现率Agent.md】

**Q2 目标**：12 专项中至少 6 项验收上线；单 case 费用约 0.02–0.12 元；AI 可覆盖 28.66% 复现专项（计划覆盖 70.20%）。上线门槛：单专项 accuracy/F1 ≥ 80%+（首批 4 项实际达 85%+）。【来源：阶段验证报告 [复现 Agent 阶段性验证报告](https://xiaopeng.feishu.cn/wiki/XF97w6WB2ihOtXkIvacchIe8nmc)】

**使用链路与架构**：对话窗口输入 Job ID + 问题类别 → 提交任务 → Agent 执行（discover→download→plot→analyze→report→upload六阶段流水线）→ 结果推送至用户（CSV 报告 + HTML 查看器）。核心架构四层：Case Builder（按检测项生成输入）→ Prompt/Rubric Router（按 defect_type 选判断标准）→ Vision Regression Judge（多模态VLM提取A defect signature并在B中匹配）→ Result Aggregator（落库/人工复核队列/统计修复率）。判定结论四档：still_exists / partially_improved / resolved / inconclusive。【来源：开发计划 [闭环复现分析Agent开发计划](https://xiaopeng.feishu.cn/wiki/K9eIw7MGBiXig6kJbsdcCIX5nVv) + Reference Defect 定向回归验证 Agent [Reference Defect 定向回归验证 Agent](https://xiaopeng.feishu.cn/wiki/UXLJwAGpei90YfkfaD9cLwy4nVM)】

**已支持12类问题**：加减速顿挫、导航变道晚/走错车道、道内画龙、变道/绕行/分合流/主辅路摆动、进逆向车道、不加速/加速慢（跑不到限速）、红绿灯相关问题（闯红灯/冲黄灯）、不减速/制动不足（撞动态车/VRU）、异常减速、压线、不居中/贴边、撞路沿/障碍物。【来源：开发计划 [闭环复现分析Agent开发计划](https://xiaopeng.feishu.cn/wiki/K9eIw7MGBiXig6kJbsdcCIX5nVv)】

**新问题接入机制**：基于 reference-defect-onboarding skill 自动化流程，通过 onboarding_request.yaml 输入最小参数（category.id/name/aliases、known_defect、expected_fix、至少6个validation_cases），agent 依次完成 init、validate、设计证据、实现plot.py、调prompt、跑验证、评测、注册。5个子skill分工：analysis（定义判定规则）、plotting（证据图）、prompt-eval（prompt调优和离线评测）、integration（脚手架和流水线接入）、onboarding（总编排）。验收标准：category_spec校验通过、所有labeled case出图、eval正常生成、错判有明确原因、飞书机器人可调用。【来源：Reference Defect 新问题 Agent [Reference Defect 新问题 Agent 开发文档](https://xiaopeng.feishu.cn/wiki/QfsrwPVLki2r9Hk02HrcMAD4nwb)】
