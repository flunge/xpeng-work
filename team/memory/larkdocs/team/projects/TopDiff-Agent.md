## 一、背景目标

**项目定位**：闭环 Diff 分析，通过对比 A/B 两版本轨迹 Top 指标差异，定向找出导致变道晚的关键因子。是复现率 Agent 的上游能力——TopDiff 定位准后再由复现率 Agent 判断是否复现。指标代号 `closed_loop_late_lane_change`，适用场景：导航变道(Routing LC) + 避障绕行变道(Active LC)。【来源：TopDiff-Agent.md + [自动驾驶 A/B 评测定向指标设计：闭环“变道晚”检测流水线](https://xiaopeng.feishu.cn/wiki/PXZWwJBdQiU35gkIuY7cqg5wnmf)】

**技术路线**：状态机驱动的串行专家工作流（Sequential Agentic Workflow），4 节点——Node1 拓扑分化与导航依从裁判(Topological Adjudicator) → Node2 意图与博弈提取器(Attribution Node) → Node3 微观语义排雷兵(FPV Appeal Node) → Node4 激进安全稽查员(Aggression Veto Node)。输入：死线 S_dead、完成点 S_finish、1x4 BEV 连环画、Navigation_Instruction。输出：标准化 JSON（verdict / workflow_trace / final_diagnostic）。关键工程约束：uncertain 路由至 ReviewRequired 不强行判定；Node4 不直接判负而降级为 ReviewRequired 或 Mixed。【来源：[自动驾驶 A/B 评测定向指标设计：闭环“变道晚”检测流水线](https://xiaopeng.feishu.cn/wiki/PXZWwJBdQiU35gkIuY7cqg5wnmf) 变道晚检测流水线 V8.1】

**视觉横测架构**：三大核心法则——①相对度量代偿绝对测量（只问"谁更近/更平滑"不问数值）②物理逻辑解耦（开环测意图正确率，闭环测包络稳健性）③视觉信噪比最大化（纯色矢量+补色对比）。双轨引擎：闭环引擎用站程对齐+终点倒推；开环引擎用有效意图窗口截断+帧袋投票(胜率>80%判定修复)。动态曲线引擎：波形形态学审查(相位错位容忍+复杂度惩罚，阶梯点刹/高频毛刺直接判退化)。安全防线：VLM禁算数值 / 30%-70%置信度标Flickering进人工 / 单维输入原则。【来源：[自动驾驶规控 A/B 视觉横测 Agent 架构方案](https://xiaopeng.feishu.cn/wiki/TwzswsTl6iEPxLkkz59c4PScncc) 视觉横测Agent架构方案】

**评测体系(CCES)**：CCES = Safety(安全) / Comfort(舒适) / Efficiency(效率) / Compliance(合规) / Navigation(导航) 五维度泛化评价；PAT = Precision Assertion Testing 针对实车top复合场景做gating。仿真数据集三类：场景集(实车问题30s) / 长路线(NGP自驾60s) / 老司机(人驾高质量行为)。场景覆盖：高速/城区/园区地库/漫游/靠边停车，各分开环/闭环。TopDiff-Agent 在 CCES 体系内对 metric cost diff 进行有效性判定。【来源：[CCES Metric 评测体系介绍](https://xiaopeng.feishu.cn/wiki/NdEGwDJn6iRcdEkTgF2clKSbn7e) CCES Metric评测体系介绍】

**开发工作流**：整体分三区——人做(数据标注/A-B划分/标注结果下载) → Agent做(类别开发/核心开发/A-B评测) → 工具运行和交付。数据标注规范：有效性(有效/无效/转人工) + 决定性因素(cost diff区间内轨迹有无明显diff) + 关键帧证据(漏报/误报帧时间戳+严重程度)。Agent自迭代要求训练集100%准确率；数据基座存OSS，设有数据质量评判Agent辅助扩充+RC制度替代固定测试集。【来源：[Metric Diff Agent 进度整理](https://xiaopeng.feishu.cn/wiki/QqABwxADHi6UXeknT6fcu9ZknKc) + ELmuwmwcsiClzIkgnLWcNcSinYb Draft计划】
