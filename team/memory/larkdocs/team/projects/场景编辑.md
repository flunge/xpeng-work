## 一、背景目标

**项目定位与边界。** 场景编辑属于 O4-KR3，目标不是单个 case 的人工修改，而是验证 Smart Agent 生成拟人化仿真场景的两条路线：离线编辑+生产，以及实时动态规划+渲染。当前主线是离线规则链路，在线闭环路线尚未展开。

**历史演进。** Q1 的相关工作主要集中在园区抬杆、小物体、AEB 和 TFL 等场景的编辑、训练与回归，暴露出人工提交、硬编码和质量评价不统一等问题；Q2 从 2026-06-06 明确交付 CLI 场景编辑，先完成工程自动化，再推进轨迹策略和拟人化能力。6/10–6/15 完成 simworld 代码归并、CLI/UCP 批量入口和配置云端化；6/16 以后转向基于 RI Local Map、TTC 和规则模板的轨迹生成，随后打通 webviz/metric 可消费的编辑车数据链路（来源：Q1 历史周计划归档、Q2 wiki、Q2 OKR-ver1、组内日会）。

**成功定义。** 概要设计给出的验收边界是：单次提交至少 100 条经筛选场景、端到端成功率至少 95%、失败可断点续跑、拟人度达到约定人工阈值；Q2 阶段先以规则链路可跑通、可视化、可评测和可回归为完成条件，不把“在线动态规划”或“和谐化模型效果”提前写成已交付。
