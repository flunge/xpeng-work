## 一、背景目标

**项目定位**：把 A 车型的 3DGS 场景通过**改变外参**迁移到 B/C 车型，经原位渲染 + Difix 修图后做开环评测，验证"跨车型趋势一致性"。

**核心价值**：仿真场景与测试车型绑定，换车型需重新采集数据、成本极高；通过 3DGS 外参迁移**绕过数据采集**，验证泛化结论是否与真实数据一致。

**最终目标**：支撑 630 多车型发版验证（GIC 刘先明提出）；从"受控试运行"走向规模化多车型验证覆盖。

**缘起**：4/22 高炳涛 @李坤——"将现有一个车型的数据转成 3dgs、生成新车型数据，看能否得到和真实数据一样的结论"。

- **验证方法论（李坤 4/23 定）**：A 车场景集 S 泛化到 B → 取 B 的开环验证报告 b0、在 S 上跑 B 的开环原位渲染 b1，对比 b0/b1 指标趋势差；前提先证明 A 自己"原位渲染 vs 原图"的 CCES 差异可接受。这是车型泛化验证的原始设计。
- **个体差异早发现**：4/24 杨星昊即发现同一 E29 不同 clip 内外参不同、pitch 差 2°+，为后续"标定致不加速/偏右"埋下线索。

#### 已从"验证趋势一致"升级为"诊断单车个体差异"的工具（实验汇总 NNHA，12 组实验）

- **G02 单车不加速 = cam 标定问题**（实验四/五，P0 高优）：换正常 G02 calib 后加速更快；逐摄像头排查锁定 **side front left 外参**为元凶（换正常外参自车即加速）。
- **D03 多车偏右 = 外参偏差**：5039 右前相机外参偏 2°致偏右、换正常外参速度变快；4215 右后相机；5041 换外参居中提升 \~15cm（仍不完全居中）。
- **H93 跑不到限速**：H93→E29 换车型对比，E29 仿真优于 H93、与实车一致，归因车型/感知差异。
- **斑马车衣不加速**：斑马→正常车衣后车速明显提升，确认全车型不加速由斑马车衣导致（反向替换无明显变化）。
- **F30BE 安全维度**：F30 安全性差于 E29/G01/E38/F57、优于 H93/F01。
- **泛化性验证（模型 24260，P1）**：random dropout 图像/3DPE 降低车型依赖，新模型 F30/H93/F01 安全改善、E29 回退。
- 排查中：G01 温州不加速、D03 difix 联调、RCCB/RGGB calib 更新测试。

#### Metric 适用性分级（验证报告 E7klw，400+ case，H93/F01/E29）

- **强适用**：撞车（安全）——三车原生/泛化方向高度一致，cost ↓5–12%（RL4 优于 RL3）。
- **较适用**：撞 RB、不居中/贴边、公交车道、跑不到限速（F01 最稳、H93 泛化易放大，F01 ↑9–12%）。
- **弱参考**：不超慢车、横向摆动、蛇形、加减速顿挫（变化 <5%、方向常不一致）。
- **不适用**：待转区&引导线、进逆向车道（多车原生/泛化方向不一致）。

#### Difix ref 图优化（V7VM）

- **根因**：OOD——训练集缺"高对齐 + 外参小差异"样本，cross-view attention 过尖锐、直接复制 ref 图几何。
- **方案演进**：改用前后 -1 秒的图作 ref（回训练 domain）→ v1 加不同车型图作 ref(6:4) → **v3 加车身 mask（新车型车身不再被 Diffusion 修回原车型）**；最佳配置 = 新模型 + -1 秒 ref 图。
- **遗留**：cam3 近距栅栏高度未解；动态物体（车尾灯/行人动作）在 -1s 模式易丢失；部分视角 difix 仍加重 3DGS 幻影。

#### 换车型流程 & 数据集（CloudSim 需求 NA9I / gating 数据集 AfHa）

- CloudSim 换车型 = 替换 3 处字段（vehicle_name / calibration 路径 / 3dgs_config 的 multi_vehicle_calib）；目标车型 calib 由 3DGS 团队预上传 OSS，绑定原始↔目标 scenario、禁二次转换。
- 闭环 gating/换车型数据集：v1 200+ scenario（4 车型）复现率 MC 66%/PC 60%，v2 103 条 MC(AI) 79%。

> **📌 7/11 里程碑：仿真测试结论被业务采纳**——业务方(于亦奇)比对确认泛化性仿真测试结果与实车数据比例一致(F01/H93 优化对得上)，将常态化用该测试发现短板车型、指导车型数据配比与 CT/RL 调优；正向车型泛化 feature 验证也主要依赖此测试。这是"仿真结论对齐并被实车侧采纳"的关键正向信号。
