# 阶段 1.5 · 器件选型（光电 + RFID + 标签）

> 两个核心器件：**光电门**（定精确时刻）+ **UHF RFID**（认人）。本文给已定型号 + 选型标准。

## 一、光电门 —— 已定型 SICK GL6-N1112

**为什么选反射板式而非对射**：反射板式**收发一体、只一端供电+对准**，对面贴无源反光板；对射式两端各拉电、两端精确共轴，泵道两侧立杆布线难度高一个量级。计时精度两者都够（响应差异在起/终点 Δt 里抵消），故**优先反射板式**降低安装难度。

**GL6-N1112 官方参数**（已逐字核对 datasheet）：

| 项 | 参数 |
|-|-|
| 类型 | 反射板式 + **偏振滤光**（防车架金属/积水反光误触） |
| 响应时间 | **< 625µs**（开关频率 1000Hz） |
| 检测距离 | 0.07–5m（max 6m）→ **门宽务必 ≤3m 留余量** |
| 防护 | **IP67**（户外淋雨/冲洗够） |
| 光源 | 可见红光 650nm（可见红点，对准方便） |
| 供电 | **10-30V DC**（用 12V），耗流 30mA |
| 输出 | **NPN，HIGH≈供电电压(12V) / LOW≤3V**，≤100mA |
| 接线 | 3 线：棕=电源+ / 蓝=GND / 黑=信号 |
| 随附 | **不锈钢支架 + 反光板 P250**（都送，省采购） |

**波长说明（破除"户外必须 850nm"误解）**：抗户外强光靠**调制光 + 偏振滤光 + IP67 + 遮阳**，不是波长。850nm 并不比可见光抗阳光（近红外太阳辐照仍强）；真按波长抗光反而是 940nm。GL6 的 650nm 可见红光完全能户外用，且可见红点让对准更省事，极端强光直射镜头时加遮阳罩即可。

**候选横向对比**：

| 型号 | 类型 | 响应 | IP | 偏振 | 结论 |
|-|-|-|-|-|-|
| **SICK GL6-N1112** | 反射板 | <0.625ms | IP67 | ✅ | ✅ **首选**（送反光板+支架） |
| Turck QS18VN6LP | 反射板 | <0.6ms | IP67 | ✅ | 备选（反光板需另配） |
| SICK GSE6 | 对射 | ≤0.5ms | IP67 | — | 安装难，降级 |
| Autonics BEN | 对射/反射 | 1-20ms | **IP50** | 部分 | ❌ 不防水淘汰 |
| 国产 QS18 | 对射/反射 | <2ms | 未标 | 未标 | 参数需自证 |

> ⚠️ 响应时间是**固定延迟**，起/终点同型号相减会抵消 → 对圈速影响接近 0；真正要防的是抖动（工业对射款亚毫秒级可忽略）。<2ms 也够用，GL6 的 <0.625ms 更优。

## 二、UHF RFID —— 5V/TTL 模块

**已选型**：UHF RFID 读写模块（3.7-5V / TTL-UART / EPC Gen2，支持国密）+ 外接天线。

关键参数：0\~26dBm 可调功率、260 张/秒盘存、-70dBm 灵敏度；天线 60×60 陶瓷读距 \~5m / 9dBi \~12m。

**选型标准**：

- **频段**：UHF 860-960MHz（EPC Gen2 / ISO18000-6C），读距远、多标签、便宜；**不要 13.56MHz/NFC**（几 cm 车速下读不到）；
- **供电/接口**：**3.7-5V，走盒内 5V 路（勿接 12V 会烧）；TTL-UART 直连 ESP32**（免电平转换）；别选只有 Wiegand 的门禁款；
- **天线**：按门宽选，门宽≤3m 用 60×60 陶瓷（\~5m）足够；功率可调，现场调到刚好覆盖门宽避免读到邻道；
- **读取模式**：用"连续盘存"模式，车 200ms 停留内可多次读到。

## 三、无源标签 —— 三条硬指标

只要满足这三条，**哪家品牌都通用**（EPC Gen2 是国际标准）：

1. **协议 EPC Gen2 / ISO18000-6C**；
2. **中国/全频段 920-925MHz**（频段不匹配读距骤降）；
3. **真抗金属**（车架金属/碳纤，普通标签贴上去读距≈0）。

- 芯片认主流（UCODE 8/9、Impinj M730）读距稳；
- **载体**：贴金属车架用抗金属标签；贴头盔/号码牌（远离金属）可用普通款；
- **到手务必在真车架上实测读距**（datasheet 是理想值）。

## 四、采购前必确认

① RFID 读写模块供电电压（确认 3.7-5V）+ 是否 TTL 直出；② 读写器 UART 协议文档 + 例程（写驱动必需）；③ 抗金属标签在碳纤/铝车架上的实测读距；④ 过线点门宽（GL6 反射板上限 5m，务必 ≤3m）；⑤ 过线点是否露天/喷淋（定基站箱防护等级）。

| 项 | MA82 参数 | 对我们的意义 |

### 通讯协议帧格式（MA6080 V4.5.3）

```text
帧: BB | Type | Cmd | PL_MSB | PL_LSB | payload[PL] | Checksum | 7E   (总长=PL+7)
Checksum = sum(Type..最后payload) & 0xFF
连续盘存(过线读EPC): BB 00 27 00 03 22 FF FF <ck> 7E    (CNT=0xFFFF 近似连续)
通知帧(读到标签): Type=02 Cmd=22 PL=11, payload= RSSI(1) PC(2) EPC(12) CRC(2)
```

固件驱动已按此实现字节流组帧 + checksum 校验 + 通知帧 RSSI/EPC 提取（用协议示例帧做主机孪生验证，EPC/RSSI/checksum/粘包全对）。
