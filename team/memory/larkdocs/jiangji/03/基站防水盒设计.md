# 基站防水盒设计（Phase1.5 无源计时基站）

> 阶段1.5 无源计时基站的成品防水盒内部布局 + 走线 + 打孔。**盒体几何取自厂商真实 STEP**（`enclosure-200x200.stp`，2026-07 解析校正）。与 tag 防水外壳（cable-tie 绑扎那篇）不同——此为**基站市电盒**。

## 一、盒子几何（真实 STEP 校正）

- 外部 **200×200×130mm，壁厚 3mm**。
- **内腔底面净口袋 168(X)×160(Y)mm**（STEP 底层 Z=−101 实测：X 15.9~~184.1=168、Y 20~~180=160，X 比 Y 宽 8mm），可用内高 \~120mm。
- **4 角装盖螺柱**：距各外角 9mm（中心 ±91），柱径 \~R8-10，中心 M4 螺孔——柱在 168×160 口袋外沿、只切掉四角。
- ⚠️ 原 160.5×160.5 是 datasheet 猜测值；真实 STEP 口袋更宽敞（X 向多 8mm），布局据此校正。

## 三、走线（按接线便利就近排）

- **电源链**（橙/棕）：充电线(-X PG7)→ BATT(角) → SPL2(1→2) → 分给电量表(+X壁)和 DCDC；
- **5V 链**（绿）：DCDC → SPL3(1→3) → ESP32 / RFID / DTU逻辑；
- **信号链**（蓝）：ESP32 居中，短线连 DTU(UART2)、RFID(UART1)、PC817(GL6)；
- **天线/外设**（灰）：DTU 天线馈线 →就近 -X 壁 PG7；RFID 天线馈线 →就近 +Y 壁 PG7；SICK 线 →-Y 壁 PG7 → PC817。

## 四、打孔方案

- **顶盖：不开任何孔**（全防水）。
- **+X 侧壁（同一面）**：电源开关 Ø16（金属自锁按钮）+ 电量显示器 LCD 窗 58.5×28.5。
- **接线/天线引出统一用 PG7 防水格兰头（开孔 Ø13，适配电缆 3-6.5mm）**：

  - -X 壁：充电线 PG7 + DTU 4G 天线馈线 PG7
  - +Y 壁：RFID 陶瓷天线馈线 PG7
  - -Y 壁：SICK 光电门线缆 PG7
- **SICK 固定**：SICK 装盒外，-Y 壁 2×M4 孔 + 支架把 SICK 固定到盒体。
- 全部朝下走线/滴水弯；PG7 自带 O 圈密封。
