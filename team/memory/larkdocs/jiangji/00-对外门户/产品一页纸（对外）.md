**星际骑遇 PumpTrack 智能骑行计时**——给儿童泵道骑行俱乐部 / 家庭的一站式训练数据系统。

# 我们解决什么

孩子在泵道练骑行，家长看不到「骑得快不快、进步了多少、有没有受伤」。教练靠手记和感觉。这个问题在小课包、高课时费的家庭里很影响续费。我们用**装在前叉的一枚小设备 + 一阵起终点线圈 + 手机小程序**，让数据自己说话。

# 产品长什么样

| 车载小盒（80 g 上下） | 绑在前叉，IP67 防水，磁吸充电，免工具拆装 |
|-|-|
| 起终点触发线圈 | 埋在出发 / 冲线位置，无感触发；或过起点红外门 + RFID 被动计时（车载无电源场景） |
| 小程序 | 家长 / 教练 / 俱乐部三端各有视图：圈速、轨迹、腾空、AI 点评、排行榜 |
| 4G 基站 | 泵道旁一插就能跑的通信箱，无 WiFi 依赖 |

# 三个结果

- **家长秒知成绩：**冲线那一刻手机上就弹圈速 + 动作关键指标
- **教练有量化：**一个学员一个档案，成长曲线自动出来，指导不必师传
- **俱乐部有续费抓手：**数据看板 → 成绩月报 → 会员权益，复购挂钩

# 跟普通码表 / 手表差在哪

|  | 我们的产品 | 运动手表 / 码表 |
|-|-|-|
| 计时精度 | 起点 / 终点线**微秒级**锁存 | 按键或 GPS 1Hz 起算 |
| 动作信息 | 腾空高度 / 压泵次数 / 倾角 | 没有 |
| 场地适配 | 泵道专用，自带基站 | GPS 信号遮挡时漂移大 |
