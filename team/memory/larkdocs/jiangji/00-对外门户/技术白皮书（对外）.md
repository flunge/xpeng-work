# 二、系统总览

产品由四块儿构成：

| 车载标签（tag） | 前叉绑定的智能硬件，含 IMU、唤醒电路、无线通信 |
|-|-|
| 触发基站（base） | 起终点线圈 / 光电 + RFID，提供计时触发 |
| 4G 通信链路 | 基站数据上云（适配少网或无网场地） |
| 小程序三端 | 家长（教练、管理员）实时看数据 |

# 三、核心技术亮点

## 3.1 微秒级计时

采用**设备本地微秒时钟**锁存过线时刻，传输、解码、上报是异步的，因此计时精度不受无线延迟影响。与「高速相机 / 人工掐表」相比更稳定，在泵道这种几十秒分胜负的场景下是可用的。

## 3.2 车载 IMU + 算法输出动作指标

六轴惯性传感器（IMU）200Hz 采样，内置滤波算法（专用姿态滤波器 + 误差状态卡尔曼滤波），输出：

- 姿态角度：roll / pitch / yaw
- 腾空事件 + 高度

公开的惯性姿态论文基准（VQF, Laidig & Seel 2023）下，我们的算法在同等级精度区间（动态 ≈1.6°，静态 ≈0.5°），与顶级开源保持一致、没有额外退步。

## 3.3 通信与稳定性

- 标签与基站之间用 2.4GHz 短距离通信（ESP-NOW），适应泵道范围
- 基站上行走 4G，不依赖场地 WiFi，户外场景运行稳定
- 设备具备远程升级（OTA）

# 四、精度与性能概览（系统级）

| 指标 | 数值 |
|-|-|
| 计时分辨率 | 微秒（标签本地） |
| 圈间计算偏差 | 毫秒级（同标签时钟相减） |
| 姿态动态误差 | ≈1.6°（BROAD 数据集实测） |
| 腾空高度分辨率 | 厘米级（基于气压 + IMU 融合） |
| 续航目标 | ≥ 8 小时训练日（500 mAh 电池） |

# 五、部署形态

- 一个场地一套基站 + N 个标签
- 儿童可自助绑 / 解绑标签（扫码 / BLE），俱乐部管理员端维护设备库
- 没有场地牌，器材到、线圈一开就计时

# 六、合规与安全

硬件按 IP67 防水、无开路接口设计；充电是磁吸结构；充电电路有 CBC 过充保护。数据隐私按「设备—账号绑定」隔离，不对外开放。
