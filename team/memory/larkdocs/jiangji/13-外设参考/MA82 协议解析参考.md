# MA82 UHF RFID 协议解析参考（软件设计）

<callout emoji="💡">
MA82(MA60/80 系列)通讯协议要点 + 我方 ESP32 驱动映射。提炼自厂商 C# DEMO(RFID_Reader_Cmds) 与协议 PDF。我方固件只取协议帧格式重写，不依赖其 C#/安卓 SDK。
</callout>

## 一、模块规格

- 协议：EPC Gen2 / ISO18000-6C + 国标 GB/T 29768-2013
- 接口：**TTL UART，默认 115200bps，TTL 电平 3.3V** → 直连 ESP32，无需电平转换
- 供电：3.3-5V，正常 46-248mA@5V，休眠 <2µA；单天线口 50Ω；含 NRST 低复位脚

## 二、帧格式

```text
BB | Type | Cmd | PL_MSB | PL_LSB | payload[PL] | Checksum | 7E     (总长 = PL + 7)
Checksum = sum(bytes[Type .. 最后一个 payload 字节]) & 0xFF
Type: 0x00=指令(CMD)  0x01=响应(ANS)  0x02=主动通知(INFO)
```

## 三、指令码表（从 ConstCode.cs）

| Cmd | 功能 | 我们用到 |
|-|-|-|
| 0x03 | 获取模块信息 | 开机自检 |
| 0x22 | 单次轮询 / 通知帧 | **读到标签的通知帧** |
| 0x27 | 多次(连续)轮询 | **✅ 过线连续读 EPC** |
| 0x28 | 停止多次轮询 | 停读 |
| 0xB6 / 0xB7 | 设置 / 读取发射功率 | **✅ 调功率收窄读区(认人稳定关键)** |
| 0x07 | 设置工作地区 | **✅ 设中国 920-925MHz** |
| 0xAB/0xAA | 设置/读取信道 | 可选 |
| 0xB0 | 连续载波 | 测试用 |
| 0x39/0x49/0x82/0x65 | 读/写/锁/灭活标签 | 发卡台写 EPC 时用 |
| 0x11 | 设置波特率 | 默认 115200 不用改 |

## 四、两个核心帧（我方驱动实现）

### 连续盘存指令（过线读 EPC）

```text
BB 00 27 00 03 22 FF FF <ck> 7E     // Reserved=0x22, CNT=0xFFFF 近似连续
```

### 标签通知帧（读到标签）

```text
BB 02 22 00 11 | RSSI(1) PC(2) EPC(12) CRC(2) | Checksum 7E
示例: BB 02 22 00 11 C9 3400 30751FEB705C5904E3D50D70 3A76 EF 7E
  → RSSI=0xC9(int8=-55), EPC=30751FEB705C5904E3D50D70
```

## 五、我方 ESP32 驱动映射

实现于 base-passive/main/app_main.c（`ma_parse_notify`/`ma_send_cmd`）：字节流组帧(BB..7E) + checksum 校验 + 通知帧提取 RSSI/EPC；开机发 0x27 连续盘存。主机孪生 `test_host/ma82_parser_twin_test.py` 用本协议示例帧验证(EPC/RSSI/checksum/粘包)全 PASS。

```c
// checksum
uint8_t ck = 0; for(i=1; i<=len-3; i++) ck += f[i]; ck &= 0xFF;
// 通知帧解析: 校验 BB/7E, PL+7==len, checksum, Type==02 && Cmd==22 && PL==0x11
//   rssi = int8(payload[0]); epc = payload[3..14] 转 hex(12字节)
// 组帧: 遇 BB 开帧, 逐字节存, 遇 7E 且 len>=7 -> ma_parse_notify()
```

## 六、现场配置（模块固件不用改，UART 指令设一次）

1. 连续盘存(0x27)——固件开机自动发；
2. **发射功率(0xB6)调到刚好覆盖过线断面**——认人稳定关键，出厂默认可能过大；
3. 工作地区(0x07)设中国 920-925MHz——合规+读距最优。
