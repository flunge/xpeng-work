# 阶段五　camera + UWB 全场地建模 + 车载定位 + ReID/骨骼点 + 发力融合

> **目标**：用**视觉 + UWB**对**全场地建模**并对**车载模块厘米级定位**；camera 做 **ReID（重识别）+ 人体骨骼点检测**，**融合手环数据做整体发力分析**。这是最终的"数字孪生 + 运动科学"阶段。  
> 前置：阶段二(车载)、三(视频)、四(手环)就位。

---

## 一、范围与交付

- **UWB 定位网**：场地布 UWB 锚点 + 车载/手环 UWB 标签，**厘米级实时定位 + 轨迹**；
- **全场地建模**：视觉(多相机)重建场地三维 + 赛道线；UWB 给绝对坐标；
- **视觉分析**：camera（可复用阶段三 IPcamera，或新增高帧率/多视角）做 **ReID**（跨机位认人/认车）+ **人体骨骼点(2D/3D pose)**；
- **发力融合**：骨骼点(姿态) + 手环 IMU/心率 + 车端 IMU + UWB 轨迹/速度 → **整体发力/技术分析**；
- 交付：场地三维模型 + 实时定位/轨迹 + 骨骼级动作分析 + 发力报告/可视化。

---

## 二、定位与建模方案

| 子系统 | 方案 |
|-|-|
| **UWB 定位** | 场地布 4+ UWB 锚点（DW3000/DWM3000）；车载/手环加 UWB 标签；TWR/TDOA 厘米级；与 IMU 融合(UWB/IMU 紧耦合 ESKF)抗遮挡 |
| **视觉建模** | 多相机标定 → 场地三维重建(SfM/已知尺寸)；赛道线/障碍标注；UWB 提供绝对尺度与坐标对齐 |
| **车载定位** | UWB(绝对) + 车端 IMU(高频姿态) 融合 → 厘米级连续轨迹 |
| **ReID** | 多机位下对骑手/车做重识别(外观特征)，跨相机连续跟踪 |
| **骨骼点检测** | 2D pose(YOLO-Pose/RTMPose) → (多视角/UWB)抬升到 3D pose |

## 四、算法（重头）

- **UWB/IMU 融合定位**：紧耦合 ESKF；遮挡/NLOS 处理；与视觉位姿互校。
- **场地三维重建**：多相机标定 + SfM/MVS 或已知赛道 CAD；UWB 对齐绝对坐标。
- **ReID + 多目标跟踪**：跨机位认人/认车，关联到 user_id（也可用 UWB 标签 ID 辅助消歧）。
- **人体骨骼点**：2D pose → 多视几何/UWB 抬升 3D；得关节角/重心/发力链。
- **发力融合分析**：骨骼姿态 + 手环 IMU/心率 + 车端 IMU + UWB 速度/轨迹 → 发力时序、左右平衡、技术动作评分、能量/效率、与理想线对比。
- **位置**：实时检测/定位在**边缘 GPU**；重建/深度分析/报告在**云端 GPU**。

## 六、风险

- 视觉 + UWB + 多端融合**系统复杂度最高**、成本最高 → 分步：先 UWB 定位/轨迹，再加 pose，再融合发力。
- 户外光照/遮挡/多人 → 多机位 + UWB 兜底 + ReID。
- ReID/pose 隐私合规（青少儿）→ 数据脱敏、家长授权、本地化处理。
- ROI：此阶段偏"高端/科研/标杆"，建议在前四阶段有商业验证后再投入。

> 说明：阶段五是终极愿景，**强烈建议在阶段一\~四跑通并验证市场后再启动**；相机可与阶段三复用以摊薄成本。
