# 阶段一 · 硬件接线（三模块 ↔ ESP32-S3，免 PCB）

> 车载终端 = DevKitC-1 + Si3933（LF 唤醒）+ IMU + 供电。面包板插装，扎带/EVA 固定到车架。

## 一、模块识别

| 板 | 芯片 | 用途 | 接口 |
|-|-|-|-|
| 蓝板 ICM42688 | ICM-42688-P/42686-P | 主 IMU（量产用） | SPI |
| 紫板 GY-91 | MPU9250 + BMP280 | 桌面验证 IMU + 气压计 | I2C |
| 绿板 Si3933 demo | Si3933 | LF 125kHz 唤醒接收 | SPI + WAKE 中断 |

## 二、⚠️ 供电关键：本板 5V 脚默认不对外供电

DevKitC-1 的 5V 脚默认无输出（需短接焊盘）。**全部模块用 3V3 供电 + 共地**。

现场供电链：户外 7.4V 电池 / 家用充电器+升压线 → 喂 MB-102 电源模块（6.5-10V 输入）→ 输出 5V/3.3V 到面包板轨。勿同时双重供电。

## 三、接线速查表

```
ESP32-S3 DevKitC          模块
──────────────────        ──────────────────────
3V3 ──┬─────────────────  ICM42688 VCC
      ├─────────────────  GY-91 3V3
      └─────────────────  Si3933 VCC
GND ──┴─────────────────  所有模块 GND（共地）

GPIO12(SCLK) ──── ICM42688 SCLK
GPIO11(MOSI) ──── ICM42688 MOSI
GPIO13(MISO) ──── ICM42688 MISO
GPIO10(CS)   ──── ICM42688 CS
GPIO9 (INT1) ──── ICM42688 INT1

GPIO5 (SCL)  ──── GY-91 SCL
GPIO4 (SDA)  ──── GY-91 SDA
                  GY-91 SDO→GND, CSB→3V3, NCS→3V3

GPIO8 (WAKE) ──── Si3933 WAKE 测试点（过线唤醒中断）
```

## 四、可选：A3144E 霍尔轮速（阶段二速度融合验证）

- **接线**：`VCC→3V3`（不接 5V！）、`GND→GND`、`OUT→GPIO6`（内部上拉 3V3，下降沿触发）；
- ⚠️ **绝不能"模块 5V 供电 + OUT 接 3.3V GPIO"**——开集上拉到 5V 会烧 GPIO；
- 磁铁装后轮辐条（教练调教时装 4-8 颗）。

## 五、接线后验证顺序

1. **只接 ICM42688** → 烧固件 → 串口看 `WHO_AM_I=0x47`(42688)/`0x44`(42686) + 静止初始化 `INIT→RUNNING`；
2. **加 GY-91 BMP280** → 串口看 BMP280 chip_id=0x58 + 气压读数；
3. **加 Si3933 WAKE** → 激励器通电 → 标签靠近 → 串口打印过线微秒时间戳；
4. 三者 OK → ESP-NOW 上报 → 基站收包。
