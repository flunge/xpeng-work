# 4G DTU产品基本功能是什么？

1，用户群体：4G DTU适用于工程师/创客/个人开发者等，开发物联网产品，终端客户不能直接使用。

2，支持协议：TCP，UDP，MQTT，HTTP，WebSocket通信协议和云服务器进行连接。

3，支持公有云平台：阿里IOT，腾讯IOT， 华为IotDA , 移动物联网平台，电信AIoT，涂鸦云，ThingsCloud 。

4，硬件通信接口：TTL UART（兼容3.3V和5V），RS485，RS232。

5，基础数据传输：数据透传，串口收到什么，就转发给服务器。

6，高级数据传输：通过任务或者数据模板（通过Lua语言二次开发）支持协议转换，数据分析，边缘计算等功能。

# 二台4G DTU能互传数据吗？

多台4G DTU相互之间数据传输不能直接传送，需要借助于公网服务器转发才可以，银尔达目前不提供这种云平台功能。

推荐搭建使用MQTT服务器来做。A设备订阅B设备的发布，A设备发布B设备的订阅。

免费的公网服务器可以使用EMQTT（[https://cloud.emqx.com/console/](https://cloud.emqx.com/console/)），不需要部署，在线使用，免费100万条数据。当然也可以用其他服务器，比如阿里云或者自建服务器。

# 你们4G DTU是否支持定位功能，精度大概多少？

# **DTU固件的识别方法**

由于模组有AT固件和DTU固件区分，所以在使用之前，需要确认固件版本。

1. 移除SIM卡后启动设备；
2. 观察指示灯状态：

- 当NET LED和RDY LED同步呈现5秒闪烁周期（亮5秒/灭5秒）时，表明是DTU固件；
- 若设备仅配备NET LED且该指示灯以5秒周期（亮5秒/灭5秒）闪烁，同样判定为DTU固件；
- 其他异常闪烁模式均属于AT固件特征。

# **DTU固件LED状态描述**

通过LED状态判断设备运行状态

|  |  |  |
|-|-|-|
| 指示意义 | 现象 | 备注 |
| 供电正常 | PWR LED常亮，并且明亮 |  |
| 供电不正常 | PWR LED不亮，或者微亮 |  |

# **DTU固件参数不能更新，DTU连接不了服务器**

1，确认固件，去掉卡，重新上电。如果是LED 5秒亮、5秒灭，就是银尔达DTU固件

2，如果固件都正常，就判断SIM卡是否能注册网络。通过DTU LED状态描述，观察设备当前的状态，判断设备SIM卡是插反，或者SIM卡是否注册网络；

3，如果网络都正常，检查WEB平台的设备否有分组（创建分组后，要把设备移动到对应分组）；

4，对比设备的真实IMEI和WEB平台的IMEI是否一致；

5，检查一下客户之前是否设置过参数密码，但是现在没有设置参数密码；

6，设备按relaod按键5秒以上，回复出厂设置在试试。

# NPN、PNP传感器选择方法

关于NPN还是PNP传感器的选择方法:NPN 输出，平常是高电平或者悬空，触发后变成低电平;PNP输出，平常是低电平或者悬空，触发后输出高电平。

如果RTU输入高电平触发的，所以需要需选择PNP传感器。比如RY1880/18811/1210

如果RTU输入低电平触发的，所以需要需选择NPN传感器。比如RN21100

如果RTU是干接点输入的(IN和COM导通触发，本身还是高低电平触发)，测量COM电压，如果COM电压是高电平，选择PNP传感器，如果COM是低电平，选择NPN传感器。

# 使用4G RTU做脉冲计数应用说明

关于输入脉冲计数问题。DTU固件不合适脉冲计数，因为DUT以网络优先，网络异常就会重启尝试恢复设备，会丢失计数记录。一般建议外部加计数器，用串口读取，然后在上传或者定制固件，定制不重启逻辑固件。

# 4G 模块IP地址说明

1、DTU固件目前不能查询IP地址，AT固件支持查询；

2、4G模块给服务器通讯的地址，不是模块的地址，是基站地址，每次都会变化，所以通过IP地址区分设备没用，不是固定的，也不是4g 的， 就连IP地址的归属地也是随机的。

3、某些专网卡的IP是固定的，这种是特殊卡或者内网卡。这种卡需要特殊渠道办理。
