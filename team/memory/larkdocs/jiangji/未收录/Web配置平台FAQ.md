# Web配置平台FAQ

> 来源: https://yinerda.yuque.com/yt1fh6/4gdtu/teuqiunped9pxcf0  
> 路径: DTU产品FAQ > Web配置平台FAQ

# Web配置平台有什么作用？

1，DTU设备的参数管理，支持批次设置参数，远程更新参数等功能。

2，管理DTU使用的SIM卡，查询卡的套餐以及流量消耗情况。

# 4G DTU连接Web配置平台，更新规则是什么？

1，设备断电重启/自动重启的时候，会访问Web平台，更新最新参数。

2，设备上电24小时之后，会自动访问平台，更新最新参数。

备注：打开自动更新参数，设备才能到服务器请求参数，如果关闭了自动更新，设备将永远无法更新参数，除非设备本地恢复出厂设置（默认是打开的）；

恢复出厂设置的方法是按reload按键7-15秒。

# **WEB平台设备列表没有设备**

新注册的账号，没有任何设备，自己可以在设备列表里添加设备。



# **WEB平台添加设备的时候，提示设备不存在**

首先检查IMEI是否正确；目前平台不需要填写SN,SN不能填写。

如果正确还提示不存在，说明设备没授权，需要联系销售生产授权。

# **WEB平台创建分组后，分配设备时没有设备可分配**

首先检查设备列表里面是否有设备，如果没有自己添加设备；然后确认创建分组时选择的设备型号是否与设备列表的设备型号相同，只有型号相同才能分配；如果发现设备型号与实际设备型号不匹配需要联系销售处理

# **WEB平台可以控制设备，重启设备，监控设备数据吗？**

不能，WEB 平台只是用于参数设置，不做任何控制，数据也不经过WEB平台。

# WEB配置平台异常，是否会影响之前设备的工作?

已经更新过的不会，设备会连续请求参数5次，如果都不成功，设备还会按照之前设置的参数运行。如果是新增设备就会导致设备参数更新异常。

# 设备被移除WEB分组，参数是否会更清除？

设备里的参数会保存之前设置过的参数，不会清除。只有当服务器给设备重新设置了参数，DTU才可能会更新新参数。

# **DTU 请求参数需要消耗的流量**

如果没有参数更新，一次请求大概消耗1KB；如果参数更新，根据配置参数而定，普通配置基本不超过1KByte。

# **数据模板作用**

数据模板，一段有数据后触发的可执行的代码，不可以有延迟函数。编写后，用过WEB动态配置到DTU里面。用于数据转换。比如自定义解析modbus协议的数据，过滤数据后发送到服务器；处理HJ212等协议。

# **任务作用**

DTU任务，一段一直执行的代码，可以有延迟函数。可以完成数据模板的功能以外，还可以完成做任何的数据处理和自定义打包逻辑，自定义采集任务，自定义上报间隔和周期等。相当于在DTU架构上面做微开发。灵活方便快捷。

如果客户有转需求，可以联系销售安排工程师评估代写。
