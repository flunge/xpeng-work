# 简介

YED-RY1440 RTU是由银尔达（yinerda）推出的工业级、高性价比RTU 。工业级、稳定、可靠。适合设备控制，状态检测，传感器数据采集等通过4G网络与服务器通讯的场景特性如下:

1. 支持直流7\~36V宽电压供电；
2. 支持供电电压检测；
3. 支持标准35mm导轨安装，塑料外壳；
4. 支持接触放电±8KV，空气放电±15KV；
5. 工作环境为-35℃-75℃；
6. 支持1路RS485；
7. 支持1路可控电源输出(控制对外供地电源)；
8. 支持4路干接点量输入；
9. 支持4路继电器输出(220VAC/10A )，模组软件重启不改变继电器状态；
10. 支持1路SPK，可以直接驱动8欧2W喇叭，进行TTS播报；
11. 支持1路耳机，可以外接带功放喇叭，进行TTS播报；
12. 支持银尔达DTU透传固件，支持TCP、UDP、MQTT、HTTP、阿里云IOT 、腾讯IOT；

**13) 支持标签logo定制服务；**

**14) 支持二次开发。**
