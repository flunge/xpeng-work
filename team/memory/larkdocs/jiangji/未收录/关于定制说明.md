# 一、标签定制

提供logo，产品型号，配色等设计，有设计师专门配合设计，样品一般一个星期出样品。

# 二、硬件定制

提供需求，基于我们的标品修改，增，减资源，外壳匹配，改版等简单需求，一般样品1个星期，中间是测试验证时间不定，生产需要2个星期(特殊情况可以加急1个星期）
