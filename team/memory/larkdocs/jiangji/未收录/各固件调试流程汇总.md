# 阶段一 · 各固件调试流程汇总

> 阶段一目标：桌面走通"计时触发 + 传感数据 → ESP-NOW → 基站 → 云 → 小程序"。先能用 > 完美。  
> 三个固件：**① 车载 tag**、**② 基站 base**、**③ 激励器 exciter(CSM 成品)**。  
> 开发框架决策见 `ESP32-dev-framework-flashing.md`；硬件细节见同目录 `Si3933-CSM-…` / `ICM42688-…`。

---

## 总调试顺序（先分块点亮，再串链路）

```
A. IMU 独立      ②  Si3933 唤醒+计时      ③ ESP-NOW 两节点      ④ 上云+小程序      ⑤ 上车
(车载tag桌面)  (车载tag+激励器)        (tag↔base)            (base→腾讯云)       (扎带固定实测)
```

每块单独验证通过再往下串，避免一次性排查多故障。

---

## ① 车载 tag 固件（ESP32-S3 ① + ICM42688 + Si3933）

**职责**：LF 唤醒锁微秒时间戳 + IMU 姿态/腾空 → ESP-NOW 上报 odom。

**开发迭代**

1. PlatformIO(Arduino) 跑 `firmware/reference/ICM42688/icm42688.ino` → 串口确认 WHO_AM_I(0x47/0x44) + 原始数据，验器件真伪与接线。
2. 转 ESP-IDF：写 `common/drivers/imu`（SPI+INT1，开机读 WHO_AM_I 自适配）→ Madgwick 姿态 → 腾空检测(0g, H=gT²/8)。
3. 写 `common/drivers/si3933`（SPI 配 R0/R1/R5/R6/R16，Scan 模式，32 位向量）；WAKE→GPIO 中断 **ISR 锁 esp_timer 微秒戳 + 入队**。
4. `uplink_task`：ESP-NOW 发 odom 状态量（姿态/腾空/过线时间戳/起点终点码），不发原始 IMU。

**烧录**：USB 连 DevKitC ① → VSCode `Flash + Monitor`（115200）。

**验证点**

- 串口打印 IMU 姿态合理（静止≈水平，翻转跟随）。
- 经过激励器触发区 → 立刻打印唤醒 + 微秒时间戳 + 起点/终点向量。
- ESP-NOW 发送计数递增（基站侧能收到）。

---

## ② 激励器 exciter（CSM 调档式，成品）

**职责**：在过线点连续发射 125kHz，进区即唤醒 tag 的 Si3933。

**开发迭代/配置**

1. 供电：5V 或 12V，**电压切换开关必须与电源匹配**（否则烧板）。
2. 四档开关选 **0.5m 档**（窄触发区，赛道宽 2m 避免提前唤醒）。
3. Studio/上位机设 Scan 模式 + 32 位唤醒向量；**起点、终点两台激励器设不同向量码**。
4. 示波器在天线测试点确认谐振 ≈ **125kHz**。

**烧录（如需更新激励器固件）**：CSMISP_1.0.6 → "程序文件" → 选 `Transmit1/基站源码` 下 default 的 `.elf` → "下载编程" → 按复位键。

> 注：CSM32RV20 是激励器自带 MCU；**标签端不烧 CSM32RV20**（标签端只用 Si3933 芯片，由 ESP32 驱动）。

**验证点**：demo 指示灯闪烁；tag 进区被唤醒；起点 vs 终点向量码不同。

---

## ③ 基站 base 固件（ESP32-S3 ②）

**职责**：收 tag 的 ESP-NOW 包 → WiFi 上腾讯云（COS/SCF/DB）。

**开发迭代**

1. ESP-IDF：`espnow_recv` 注册回调，解析 odom + 过线时间戳。
2. WiFi STA 连网；HTTPS POST/MQTT 上云（**带设备密钥/TLS 鉴权，勿裸开端口**）。
3. 圈速 = 终点时间戳 − 起点时间戳（均为 tag 端微秒戳，不用基站收包时刻）。

**烧录**：USB 连 DevKitC ② → `Flash + Monitor`。

**验证点**：收到 tag 包计数与 tag 发送计数一致；云端 DB 出现记录；小程序按 user_id 展示圈速/腾空。

---

## ④ 上云 + 小程序（链路收尾）

- 云端：COS 存数据、SCF 算圈速、DB 存结果；数据绑 user_id。
- 小程序：读云端展示（不直读板载 flash）。
- 验证：一次完整过线 → 几秒内小程序看到本圈圈速 + 最高腾空。

## ⑤ 上车实测

- 扎带/魔术贴把 tag 固定在车架主三角（不装前叉）；MB-102 供电链。
- 慢骑→提速，观察唤醒稳定性、时间戳抖动、ESP-NOW 丢包率。
