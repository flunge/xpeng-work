# 一、简介

银尔达IOT平台，是银尔达研发的物联网平台。用户可以很方便的把传统不联网的设备，通过DTU对接到平台，实现设备的远程管理和监控。

功能支持设备的连接，管理；支持设备数据定义，解析，处理，储存，统计；支持小程序/APP管理对接；发送电话、短信、微信、邮件等报警信息通知；支持服务与服务器对接；支持服务器边缘计算数据；支持私有化部署,log替换，特殊功能定制。

平台后续会一直升级维护，增加新功能。
