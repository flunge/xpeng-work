# 11、DTU透传固件发送短信命令

> 来源: https://yinerda.yuque.com/yt1fh6/4gdtu/toi12f0ybed582hx  
> 路径: DTU指令手册 > 11、DTU透传固件发送短信命令

目前Air780支持。先开启短信功能，然后可以发送和接收短信，不能自己给自己发送短信。

固件版本V1.1.1版本支持

# 1、开启短信功能命令-smson

开启了缓存，才能读取接收的短信，并且通过任务读取接收的短信。

|  |  |  |
|-|-|-|
| 功能 | 开启短信功能 |  |
| 设置参数 | 参数 | 描述 |
|  | 是否开启 | 0:关闭 1:打开 |
|  | 是否过滤 | 0:关闭 1:过滤 |
|  | 允许号码 | 不过滤用0占位 |
|  | 短信上报格式 | 0:不上报 1:固定格式 2:自定义格式 |
|  | 短信上报格式 | 不上报用0占位 |
|  | 上报通道 | 1\~n |
|  | 内部缓存 | 0:关闭 1:开启 |
| 返回参数 | 无 |  |
| 设置实例 | config,set,smson,1,0,0,0,0,1,1\r\n \r\nconfig,smson,ok\r\n |  |
| 查询参数 | 无 |  |
| 返回参数 | 与设置参数一致 |  |
| 读取实例 | config,get,smson\r\n \r\nconfig,smson,ok,1,0,0,0,0,1,1\r\n |  |

# 2、发送和读取短信命令-sms

注意：发送短信必须要自己的实名认证的手机卡（Air780系列支持移动，联通，Air780EHV/Air8000支持移动、联通、电信）。自带贴片卡，物联网卡不支持短信功能。

需要先开启短信功能。

设备在上电期间，最多缓存10条接收短信，掉电后会删除缓存。

|  |  |  |
|-|-|-|
| 功能 | 发送短信 |  |
| 发送短信 | 参数 | 描述 |
|  | 电话号码 |  |
|  | 短信数据 | 发短信的时候先把UTF-8的16进制编码转换成16进制格式的字符串 |
| 返回参数 | 发送状态 | 0:失败 1:成功 |
| 设置实例 | config,set,sms,199xxxx6558,3132332CE68891E79A84E5AEB6EFBC8C40616263\r\n \r\nconfig,sms,ok,1\r\n 发送短信内容是 "123,我的家，@abc" 注意：发送短信必须要自己的实名认证的手机卡（Air780系列支持移动，联通，Air780EHV/Air8000支持移动、联通、电信）。自带贴片卡，物联网卡不支持短信功能。 |  |
| 读取短信参数 | 无 |  |
| 返回参数 | 电话号码 |  |
|  | 短信内容 | UTF-8的16进制编码转换成16进制格式的字符串 |
| 读取实例 | config,get,sms\r\n \r\nconfig,sms,ok,199xxxx6558,3132332CE68891E79A84E5AEB6EFBC8C40616263\r\n |  |
