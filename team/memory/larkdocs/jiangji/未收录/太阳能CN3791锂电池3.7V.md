# 二、简介

本模块核心功能为通过太阳能光伏输入，实现对3.7V/4.2V锂电池的高效充电，同时支持两路并联设计（一路充电、一路供电输出）。

可以配合3.3\~4.2V DTU改造成太阳能充电供电方案。

## 1、硬件参数

|  |  |
|-|-|
| 功能 | 详细参数 |
| 电源输入 | 5-28V太阳能光伏输入，支持防插反默认推荐5V太阳能板(MPPT调整为5V)。 |
| MPPT功能 | MPPT功能，默认调整的5V |
| 最小充电输入电压 | 4.9V |
| 充电电流 | 默认500mA，可定制最大4A |
| 输出 | 两路并联，可以同时一路充电、另一路供电输出 |
| 接口 | 2.54接口 |
| 漏电流 | 10ua。太阳能充电板不充电的时候，电池有10ua漏电 |

## 2、硬件资源

|  |  |  |
|-|-|-|
| 编号 | 标识 | 说明 |
| 1 | VIN GND | 太阳能光伏输入 VIN是正极，GND是负极 |
| 2 | BAT GND | 可以一路做电池充电，另一路供电输出。 端子是并联的。（不支持同时两路电池充电） BAT是正极，GND是负极 |
| 3 | BAT GND |  |
| 4 | LED | 充满绿色，充电红色 |
