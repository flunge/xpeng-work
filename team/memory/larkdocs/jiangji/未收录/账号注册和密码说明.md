# 账号注册和密码说明

> 来源: https://yinerda.yuque.com/yt1fh6/4gdtu/tegmdew2wkgim8sv  
> 路径: Web配置工具 > 账号注册和密码说明

# 一、账号注册

注册连接:[https://dtu.yinerda.com](https://dtu.yinerda.com/)

大陆地区可以使用手机号注册和邮箱注册，其他区域可以用邮箱注册，根据喜好注册。

注册的时候要注意密码，密码必须是 数字、字母和特殊符号的3种方式组合，并且长度至少6个字节，否则无法注册。比如用有字符和数字的邮箱作为密码方便记忆。

注册的时候如果收不到验证码，可以耐心等到几分钟，不用重复获取验证码，如果确实一直注册不上，可以联系销售后台手动创建账号。

# 二、密码的用途

登录账号后，在分组里面删除设备，解绑设备，导出数据等都需要输入密码验证，这个密码就是账号的登录密码。密码和很重要，妥善保管。

# 三、注册账号的建议

建议使用公司老板，负责人，或者其他稳定人员的信息注册，防止人员离职流动，带来设备归属和设备转移问题。

# 四、设备解绑说明

当发现设备被其他人绑定的时候，可以联系销售查询绑定人和账号，但是销售是不能去解绑设备，必须确认设备归属，经过设备绑定人允许后才能解绑。如果是你同事或者认识的人绑定了，建议先直接联系绑定者先处理。如果拿一些不属于自己的设备找销售解绑，这个是不被允许的！

## 账户可以正常登录

客户使用自己账号登录DTU Web平台手动解绑设备。

## 账户不能正常登录

### Web管理平台账号为手机号码：

银尔达电话通知客户，登录银尔达WEB管理平台，进行手动解绑，或者变更账户信息。如果联系不到客户，需要对方公司提供如下信息：  
1，提供原账号的电话号码实名认证信息。  
2，提供该员工在公司的在职证明或者离职证明。  
3，提供设备采购订单，和设备IMEI设备列表，核对是否对应。  
4，提供因设备解绑而造成的损失免责声明。  
5，提供新管理员账号信息。
