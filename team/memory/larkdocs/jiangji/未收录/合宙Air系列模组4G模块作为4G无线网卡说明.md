# 合宙Air系列模组4G模块作为4G无线网卡说明

> 来源: https://yinerda.yuque.com/yt1fh6/4gdtu/ug2kwuim19bor7gk  
> 路径: 合宙Air系列模组4G模块作为4G无线网卡说明

AT固件可以用USB作为4G网卡使用，使用RNDIS上网，就像一张无线网卡一样使用。前提是你的主机是跑windows，linux或者安卓的系统才行。银尔达无法提供技术支持，如果需要可以，详情参考官方资料询问官方技术支持。

DTU串口通讯方式不能快速传送大数据，如果作为网卡使用，就可以最大限度的发挥4G模块的速度，比如摄像头用来传送视频文件，与市面的4G 路由器一样的道理。
