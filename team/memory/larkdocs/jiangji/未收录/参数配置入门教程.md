# 注册账号

浏览器登录

，使用手机号或者邮箱注册账号。

# 添加设备

设备管理->设备列表->添加设备。可以用微信扫码设备IMEI后添加（**不用填写SN**），如果添加成功，能看到**产品型号**和设备IMEI。**产品型号**后面创建分组需要使用。

如果提示:“找不到此设备”表示设备没授权，核查一下设备IMEI是否输入正确，如果正确需要联系销售授权后再添加。

如果提示被“被其他账号绑定”，也需要联系销售处理。

# 创建分组

参数设置->分组管理->创建分组。分组名称自定义，分组产品型号必须和设备列表显示的“产品型号”一样。

# 分组添加设备

分组添加设备方法在**参数设置->分组管理->设备列表->分配设备**。在分组里面添加设备，这些设备的参数就会和分组一样。可以点击查找或者F5刷新页面数据。如果在分配设备的时候，找不到你添加的设备，一般就是分组型号和设备型号不一样导致。



# 配置参数

参数设置->分组管理->参数配置。进入参数配置，当配置好参数后，点击“保存参数”，确认保存后，就修改了参数。新创建的分组没有参数，需要点击“保存参数”后才会保存新参数，修改产生后只需要点击一次保存即可。

注意串口参数默认是关闭的，需要打开串口才能通讯。

参数修改后，点击一次保存，保存参数。

# 设备更新参数

确认设备能正常联网后(NET LED 500ms闪烁)，**断电重启设备**，设备自动更新参数,重启设备等20-30秒刷新网页。

没更新参数的时候:

断电重启设备更新后的状态:

设备管理->设备列表。可以通过分组参数版本=设备参数版本，确认设备是否更新了参数。

# 设备信息查询

设备管理->设备列表->详情。当参数更新了后，可以看到设备的更多的东西比如ICCID和固件版本号。ICCID可以用来查询SIM卡是否停机，固件版本号可以用来确认产品是否有更新最新功能。

# SIM卡管理

SIM卡管理->SIM卡列表。可以看到更新参数的设备的SIM卡信息，方便客户续费SIM卡。银尔达提供的SIM卡可以看到卡的流量。客户自己的卡只能记录ICCID信息。

# 设备删除或更换分组方法

当设备不需要使用、设备需要添加到其他账号下面、设备需要更换分组的时候，需要先把设备移除分组，然后再去操作其他的步骤。

**设备分组移除:**

操作路径是:**参数设置**->**设备列表**->**移除**设备。

**删除设备:**

如果**设备管理**->**设备列表**，如果删除设备按钮是灰色的，说明不能直接删除，需要在分组里面移除设备后再删除。

**设备更换分组:**

一个设备只能在一个分组里面，如果要更换设备分组，需要在原有的分组里面移除设备，然后在新分组里面添加设备。

**删除分组:**

删除分组是灰色的时候，表示分组不能删除，需要移除分组里面的全部设备后，分组才被能删除。
