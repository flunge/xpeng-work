# 简介

YED-RY25500 RTU是由银尔达（yinerda）推出的高性价的远程控制器，适合设备控制，状态检测，传感器数据采集等通过4G网络与服务器通讯的场景，特性如下:

1. 支持宽输入电压范围8\~60V；
2. 支持接触放电±8KV，空气放电±15KV；
3. 工作环境为-35℃\~75℃；
4. 支持 5 路光耦继电器输出；
5. 支持 5 路光耦干接点输入检测；
6. 支持1路ADC，可以直接采集供电电源电压；
7. 支持1路RS485；
8. 支持1路DS18B20温度采集；
9. 支持硬件看门狗，运行稳定不死机；

10)支持银尔达DTU透传固件，支持TCP、UDP、MQTT、HTTP、Websocket,阿里云IOT 、腾讯IOT、OneNet，华为IOT，电信云，涂鸦云、ThingsCloud等平台；

1. 支持标签logo定制服务；
2. 支持二次开发定制;

13)支持SSL证书加密TCPS/MQTTS/HTTPS 协议；

# LED状态描述

## NET和RDY/STA LED描述

|  |  |  |
|-|-|-|
| 指示意义 | 现象 | 备注 |
| SIM卡不识别 | NET LED 和RDY/STA LED 5000ms亮 5000ms灭 |  |
| SIM卡正常，但注册不了网络 | NET LED 100ms闪烁,RDY/STA LED 熄灭 |  |
| 注册网络成功，但没连上服务器 | NET LED 500ms慢闪,RDY/STA LED熄灭 | 没有任何通道链接服务器 |
| 成功连上服务器 | NET LED 1000ms慢闪,RDY/STA LED常亮 | 至少有一个通道链接服务器成功 |
