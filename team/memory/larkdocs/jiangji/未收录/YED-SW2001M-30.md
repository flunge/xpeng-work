# 简介

YED-SW2001M-30-RTU版本适合设备控制，状态检测，传感器数据采集等通过4G网络与服务器通讯的场景，具体功能特点如下。

1. 支持220V/380V供电；
2. 支持导轨安装和定位孔安装，外壳阻燃材料；
3. 支持接触放电±8KV，空气放电±15KV；
4. 工作环境为-35℃\~75℃；
5. 支持1路220VAC 30A/30VDC 30A 继电器控制；
6. 支持2路干接点开关量输入检测；
7. 支持1路RS485；
8. 支持1路RTC本地时钟；
9. 支持1路12V 100ma可控电源输出，可以给传感器供电；
10. 支持硬件看门狗，运行稳定不死机；

12)支持银尔达DTU透传固件，支持TCP、UDP、MQTT、HTTP、Websocket,阿里云IOT 、腾讯IOT、OneNet，华为IOT，电信云，涂鸦云、ThingsCloud等平台；

1. 支持标签logo定制服务；
2. 支持二次开发定制;

15)支持SSL证书加密TCPS/MQTTS/HTTPS 协议；

16)支持给用户设备进行固件升级。

# LED状态描述

|  |  |  |
|-|-|-|
| 指示意义 | 现象 | 备注 |
| SIM卡不识别 | NET LED 5000ms亮 5000ms灭 |  |
