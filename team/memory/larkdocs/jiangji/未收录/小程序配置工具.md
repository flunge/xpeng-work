# 一、简介

银尔达DTU透传固件，支持微信小程序配置，方便在没有电脑的时候更改参数。

主要功能如下:

1)与WEB配置平台功能基本一致；

2)可以通过扫码的方式添加设备；

3)可以参看设备的SIM卡信息;

4)不能配置和修改任务和数据模板(数据量多，操作不方便)；

# 二、小程序二维码

可以微信收搜“DTU管理平台”，或者微信扫描二维码关注，账号和WEB平台账号一样。
