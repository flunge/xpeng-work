# DTU测试异常解决方法FAQ

> 来源: https://yinerda.yuque.com/yt1fh6/4gdtu/os1xtgyl8p9buevo  
> 路径: DTU产品FAQ > DTU测试异常解决方法FAQ

# 一、WEB参数无法更新排查方法

注意只有DTU固件支持WEB配置，AT固件不支持，卡插好，天线接好，并且保存参数后，需要设备重启才能更新参数。

1、确认WEB添加的设备，是否分配到了分组，如果分组设备数量为0，表示分组里面没设备。

2、确认SIM卡的状态，如果只有设备LED为500ms亮500ms灭或者1000ms亮1000ms灭才表示网络正常。其他状态表示SIM卡不识别或者停机或者固件不对。

3、长按Reload按键7秒，恢复出厂设置试试。

4、确认SIM卡是银尔达的还是自己的，如果是自己的找运营商确认卡是否是定向卡，如果是定向卡需要添加dtu.yinerda.com到SIM卡运营商白名单，或者换个手机卡试试。

5、通过以上方法基本就能解决了，如果还是不能解决可以拆开外壳或者通过串口发送config,get,imei\r\n读取IMEI，与平台的IMEI对比，确认是否IMEI对应问题导致。

# 二、RS485调试数据数据异常排查方法

异常的现象是发送数据或者就收数据不全，有乱码，或者丢失的现象。

1、检查波特率，校验位这些是否正确，特别注意一些电表数据是偶校验。

2、修改EN反转时间参数，EN默认为0。当异常的时候，如果Air724系列,EN 可以设置成1试试；如果是AIr780系列，EN设置成5000\~20000，优先用5000调试一下，波特率越小，EN越大，2400波特率 需要调整到20000。

原因是EN 反转时间影响总线的数据传送。如果反转快了，串口收到的数据末尾是乱码，如果翻转慢了，收到设备应答的数据是乱码。对应的就是从设备还没接收完成4G模块就翻转了和从设备已经应答了4G模块还没准备接收。

# 三、NET LED 疯狂闪烁的排查方法

疯狂闪烁是说100ms亮100ms灭非常快。这种状态是卡注册不了网络导致。

1、确认4G天线是否接好，天线都必须接，IPEX天线必须接，SMA天线不接有点信号，信号不好。

2、如果在偏于地区，山区，地下室，可能信号不好连接不上。

3、SIM卡是否过期了或者换设备锁卡了。

4、如果是银尔达的SIM卡提供ICCID，给销售查询SIM卡状态。

5、如果是自己的，找卡供应商查询卡状态

# 四、DTU数据不通的调试方法

客户设备+DTU+服务器数据无法正常交互，数据不通，设备无法控制，原因很多。总体原则是先排查硬件再排查软件；先用银尔达提供的测试系统，然后再用客户自己的系统。

排查DTU本身是否有问题:

1、先拍20秒LED视频，观察设备状态，排查卡，天线等是否正常.

2、保证DTU供电稳定，有的客户使用电脑USB转串口供电或者自己主板供电，功率不足，会导致各种问题。

先推荐独立电源你供电，或者购买银尔达的测试套餐、测试工具。

3、使用USB转串口工具，直接连接DTU，验证DTU本身的串口硬件是否正常，发config命令有应答，表示正常。

4、使用DTU连接银尔达测试服务器，配合电脑USB转串口工具，测试数据流，网络数据能发能收表示正常。

通过上述问题后基本就能确认4G模块没问题。然后根据情况去替代。排查客户环境是否有问题:



如果是客户服务连不上，先使用电脑客户端连接客户服务器，看电脑客户端是否能连上，如果能连上，核查DTU参数是否正确。如果电脑客户端都连不上，表示客户服务器有问题。



如果是客户服务器能连上，但是下发数据客户的设备不响应，但是使用银尔达测试服务器下发可以。可以使用USB转串口工具连接DTU，观察服务器下发的原始数据是什么，2个服务器对比一下即可。大概率不是HEX模式。



如果是客户设备与DTU之间串口无法通讯，但是客户设备与电脑工具通讯正常，电脑工具与DTU也通讯正常。大概率是校验位可能不对，或者硬件不匹配。客户主板的TTL串口可能有上拉电阻导致的。
