# 0、SIM卡批量管理和续费方法

参考: [https://yinerda.yuque.com/yt1fh6/4gdtu/gqv4wlgiht4oeffu](https://yinerda.yuque.com/yt1fh6/4gdtu/gqv4wlgiht4oeffu)

# 物联网卡从形态上有什么区别？

注意：我们DTU 外壳卡一般采用外置卡+贴片卡的方式，标准卡（Standard），中卡（Micro），小卡（Nano）是外置卡，更换简单，但是存在松动和生锈而导致接触不良的情况。贴片卡是芯片是芯片卡，可以直接焊接到电路板上，接触牢固，但是更换比较麻烦。

如果设备工作环境里面有震动，高温，高湿，腐蚀气体环境等强烈建议使用贴片卡，但是提前需要预估设备使用流量大小，使用合适的流量套餐。

# DTU双卡方案如何工作的？

如果插了外置卡，优先使用外置卡，如果没有接外置卡，使用内置卡。

如果需要根据某种逻辑自动切换，需要定制固件。

# DTU默认贴片的SIM卡介绍

1，激活：DTU上电，内置SIMA卡自动激活。

2，卡套餐：30M/月，最大可以升级套餐100M/月（研发产品需要慎重评估）

3，续费：可以续1年或者多年套餐，到期前2个月找我们销售续费，如果销卡后，无法续费。

4，限制：无限制。

# **SIM卡后台查询状态正常，设备连上不了网络？**

1，确认SIM卡是否插反了。

2，SIM卡不能更换设备，换设备使用后，SIM会锁卡，解锁非常麻烦（务必重视）。

3，如果手机卡测试，如果可以正常使用，找销售处理按照特殊渠道处理。

4，如果有内置卡，内置卡过期了，就必须使用外置卡，如果这时外置卡没插好或者反了，也连不上网络。

# **SIM卡机卡绑定政策**

国家对SIM卡严管，防止诈骗灯犯罪行为，实行机卡绑定正常，一张卡只能在一台设备上使用；一台设备可以使用多张卡。



# **SIM卡流量异常超标**

1，检测设备之前是否接了USB接口链接电脑。如果接了电脑，电脑会把设备虚拟成4G网卡，就会消耗4G模块的流量上网，从而导致SIM卡流量超标停机。只需要把4G虚拟出来的网卡禁用即可。

2，检查设备是否有频繁的重启，比如配置了多个通道，其中某个通道连接不上，就会导致设备重启。如果设备重启会请求WEB参数(可以关闭)每次可能有1K的流量消耗

# **SIM卡的使用地区限制**

SIM卡只在中国大陆使用，除特殊地方，基本全国通用；

SIM卡不能在边境使用，比如云南边境等地区；

SIM卡不能在西藏、新疆、云南、广西等边境敏感或者严管地区使用，需要使用当地的SIM卡。

# **SIM卡哪里查询使用流量**

1，关注银尔达电子公众号，直接在公众号里面续费。

2，找销售线下续费。

# **SIM卡哪里查询使用流量**

1，在WEB配置平台，可以查询DTU使用的SIM流量情况，但是必须是我们售卖的卡。

2，找销售开通SIM卡管理平台账号,登录 [sim.yinerda.com](https://sim.yinerda.com) 查询。



# **定向卡说明**

目前银尔达的SIM卡都不是定向卡，可以连接任意的服务器，只有自己购买的卡可能是定向卡。

表现是网络状态正常，但是无论如何都无法连接服务器，换手机卡就能连上。

# 专网卡说明

专网卡，一般是需要设置特定APN的卡。比对地铁，高校，大公司的局域网，只能连接他们内部网的卡。

这种卡只需要设置专网APN即可，设置好后和普通卡一样使用。

专网卡，一般不能使用WEB平台配置参数。可以使用串口工具配置参数，或者先试用普通卡配置参数，然后换专网卡。

# 国际卡说明

银尔达有提供国际卡。可以实现全球漫游通讯，或者在大陆生产测试，在某个其他地区使用卡(包括港澳台等)。详情咨询销售。

国际卡支持亚洲区，欧美区、非洲和南美区，还有全球卡 4种卡。支持国内生产测试然后国外正式使用。

国际卡需要提前设置正确的APN才能使用。

# 如何预估设备使用流量

把设备按正常使用环境测试，上电挂机。连续工作2-5天左右，然后在SIM卡管理平台查询SIM卡的流量消耗。就可以评估一个月需要多少流量。这个挂机时间越久，评估约准确，前期评估准确，防止流量不够停卡。SIM卡信息查询地址 [sim.yinerda.com](https://sim.yinerda.com)

需要预留一些异常流量，比如设备重启，服务器重启等，可以按正常流量的+20%预留流量选择。

计算网络协议使用流量的时候，不只计算有效负载，还需要计算本身网络协议头，比如TCP协议，每个包的IP和TCP包头就40个字节。就算你发一个字节，也是需要消耗40字节以上流量。

目前最小套餐流量是30M/月。对于偶尔设备控制，平常2-3分钟通讯一次心跳状态的设备，基本是足够的。
