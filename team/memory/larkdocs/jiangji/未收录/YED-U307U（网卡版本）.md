# 简介

U307U 核心板是由银尔达（yinerda）基于移动M307R模组推出的网卡产品 。小巧、稳定、可靠。

特性如下:

1. 支持5V USB直插供电；
2. 工作环境为-35℃-75℃；
3. 支持标签logo定制服务；

4)支持Windows,Linux,安卓系统上网功能。做成一张4G网卡使用。

# 使用方法

注意作为设备网卡的时候，必须使用手机卡、手机副卡或者是其他专门上网的流量卡，需要实名认证的卡，不能使用普通的物联网卡，物联网卡不能用在电脑，手机等人联网设备上。

## windows 系统

windows 选安装USB驱动，然后设备插上USB到电脑就能自动识别网卡，然后进行USB的发AT命令进行配置RNDIS，重启后即可。

# 如何维护网络稳定

业务层可以周期去连接服务器或者PING一个目标服务器，如果发现超时1分钟或者多久后，就可以他通过USB虚拟出来的AT串口发送AT命令自动重启模组，然后模组自动重新开始恢复上网功能。

USB虚拟出来的AT串口，还可以读取信号强度，SIM卡的卡号等命令，可以方便管理，具体命令查看模组的AT手册。
