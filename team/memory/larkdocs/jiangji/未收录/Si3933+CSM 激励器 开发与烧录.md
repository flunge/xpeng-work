# Si3933 + CSM 125K 激励器 — 开发迭代 & 烧录

> 供应商：南京中科微(CSM-IC)。资料原始包：`docs/supplier-manuals/Si3933-CSM/`、`docs/supplier-manuals/_原始压缩包/si3933.zip`。

> 源码/工具：`firmware/reference/Si3933-CSM/`（便签测试源码.rar、Studio 上位机）+ `docs/supplier-manuals/Si3933-CSM/exciter-intro-and-firmware/`（含基站源码、CSMISP 烧录工具、使用说明 PDF）。

## 0. 本项目怎么用它（架构边界，先看这条）

CSM 这套 LF 子系统含两块东西，**我们只全用激励器，标签端只取 Si3933 芯片**：

| 部件 | CSM 方案 | 我们的用法 |
|-|-|-|
| \*\*125K 激励器**（过线点发射）** | CSM32RV20(RISC-V) + 栅极驱动 + 125K 天线，调档式有 4 档电阻\*\*调激活距离 **5.5m→0.5m** | ✅ **整块直接用**（成品/可烧录）。赛道宽 2m，选 0.5m 档 → 窄触发区，避免提前唤醒 |
| **Si3933**（LF 唤醒芯片） | CSM 把它焊在 CSM32RV20 的"便签/标签"板上，自带 MCU+2.4G、1Hz 上报 | ❌ **不用 CSM32RV20 那块成品标签**；只把 **Si3933 芯片焊到我方 ESP32-S3**，WAKE→ESP32 中断 + SPI 读寄存器（板内有线，非无线） |

> 即：激励器是"现成可烧录设备"，Si3933 是"贴到我们 ESP32 上的芯片"。CSM32RV20 的烧录只跟**激励器**有关；标签端不烧 CSM32RV20。

## 1. 激励器：开发迭代 + 烧录

### 1.1 板卡认识（调档式 V1.5）

| 区 | 说明 |
|-|-|
| 电源接入 | 5V / 12V（**电压切换开关必须与实际电源匹配**，否则烧板） |
| Type-C | CH340 USB 口，可代替 5V 供电 + 串口 |
| 四档滑动开关 | 0Ω / 50Ω / 150Ω / 500Ω → 激活距离 **5.5m / … / 0.5m**（本项目选最近档） |
| MCU | CSM32RV20（QFN32，RISC-V） |
| 复位按键 | 烧录后按一下生效 |
| 125K 天线 | LF 发射线圈（量产换成薄型无凸起地感线圈） |

### 1.2 烧录步骤（CSMISP）

1. 安装 `CSMISP_1.0.6_setup`（在 `exciter-intro-and-firmware/` 内，解压安装）。
2. 打开 CSMISP → 左下角 **"程序文件"**。
3. 进入激励器固件文件夹（调档式=`Transmit1/`，普通=`基站源码/`）→ 找 `default` → 选对应 **`.elf`** 文件。
4. 显示加载成功 → 点 **"下载编程"** → **按一下板上复位键** 生效。

### 1.3 上位机配置（Studio / 基站设置软件）

- `firmware/reference/Si3933-CSM/studio-host-tool/Si3933Studio.exe`（Windows）。
- 配置 Si3933 工作模式（默认 **Scan**）、唤醒向量(Pattern)、发射参数；激励器上位机点"命令执行"→"指定设置"激活，demo 板指示灯闪烁即 OK。

### 1.4 开发迭代节奏（激励器侧）

1. 先用原厂默认固件 + 默认 Pattern(例程 69、96) 验证"能唤醒"。
2. 调 4 档开关到 0.5m 档，示波器在天线测试点确认 **125kHz** 谐振、确认触发区宽度 ≈ 赛道宽。
3. 与标签端 Si3933 对齐 **32 位唤醒向量**（起点/终点用不同码）。
4. 量产：把 125K 天线换成薄型地感线圈，灌封后重新调谐到 125kHz。

## 2. Si3933（焊到我方 ESP32）：开发迭代

> 标签端我们不烧 CSM32RV20。CSM 给的"便签测试源码"(`.rar`, CSM32RV20)只作**寄存器配置参考**，把它的寄存器序列移植到 ESP32 的 SPI 驱动里。

### 2.1 关键寄存器（来自《125K 激励器使用说明_搭配 Si3933》+ 数据手册）

| 项 | 寄存器 | 值/说明 |
|-|-|-|
| 工作模式 | — | **Scan 模式**（与激励器上位机一致） |
| 唤醒向量长度 | **R0** | 选 **32 位向量** |
| 唤醒向量(Pattern) | **R5 / R6** | 高位在前低位在后；例程 69、96；起点/终点设不同值 |
| 模式位 | **R1 bit5** | 写 **0** |
| 通道谐振调谐 | **R16(0x10)** | 逐通道调，使天线谐振 ≈125kHz（示波器测试点确认） |
| 正文数据 | — | ≤10 字节，可串口打印查看 |

### 2.2 ESP32 侧开发迭代

1. **接线**：Si3933 SPI(SCLK/MISO/MOSI/CS) → ESP32-S3 SPI；**WAKE/中断脚 → ESP32 GPIO(中断)**；按数据手册接 LC 天线 + 晶振（确认模块是否自带天线/晶振）。
2. **驱动**：ESP32 SPI 写 R0/R1/R5/R6/R16 完成配置（移植便签源码寄存器序列）；进 Scan 低功耗待机。
3. **唤醒**：进入激励器触发区 → Si3933 匹配到 32 位向量 → 拉 WAKE → **ESP32 ISR 立即锁存 esp_timer 微秒时间戳**（硬实时，见项目规则 G）→ 入队，任务里读正文数据 + 经 ESP-NOW 上报。
4. **验证**：示波器看 125kHz 唤醒帧；串口打印收到的向量/正文确认起点 vs 终点。

详细 datasheet：`docs/supplier-manuals/Si3933-CSM/Si3933_datasheet_V1.6.pdf`、`Si3933_usage-notes_V0.03.pdf`、`Si3933_MCU_简介_V1.2.0…pdf`。

## 3. 待向供应商确认（见询价文档）

- 激励器能否**连续发射**（非轮询）；4 档开关 0.5m 档触发区实测宽度。
- Si3933 模块**是否自带 LC 天线 + 晶振**，还是裸芯片需我们配。
- 32 位曼彻斯特/向量帧格式细节（与我方 ESP32 SPI 配置对齐）。
- 激励器量产供电方式（5V/12V + 内置充电电池）。
