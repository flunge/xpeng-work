# DTU透传固件LED状态说明

# 一、设备网络状态指示灯描述

设备上面一般有3颗LED灯，PWR LED，NET LED ,STA/RDY LED其意义如下。如果只有NET LED，就只需要看NET LED状态。

|  |  |  |
|-|-|-|
| 指示意义 | 现象 | 备注 |
| 供电正常 | PWR LED常亮，并且明亮 |  |
| 供电异常 | PWR LED不亮，或者昏亮 | 注意设备的USB 接口不供电 |
| SIM卡不识别 | NET LED 和RDY LED 5000ms同时闪烁 | 卡插反了/松动了/卡槽坏了 |
| SIM卡正常，但注册不了网络 | NET LED 100ms闪烁,RDY LED 熄灭 | 卡停机了/天线没接 |
| 网络正常，但没连上服务器 | NET LED 500ms慢闪,RDY LED熄灭 | 没配置参数/服务器异常/参数错误 |
| 成功连上服务器 | NET LED 1000ms慢闪,RDY LED常亮 | 至少有一个通道链接服务器成功 |

# 二、设备信号强度LED描述

某些DTU有5颗信号LED，可以用于指示信号强度

|  |  |  |
|-|-|-|
| LED亮个数 | CSQ范围 | 信号说明 |
| 5 | 26\~31 | 极强 |
| 4 | 21\~25 | 强 |
| 3 | 17\~20 | 一般 |
| 2 | 12\~16 | 差 |
| 1 | 6\~11 | 很差（不能稳定通信） |
| 0 | <6 | 不能通信 |

某些DTU有3颗信号LED，可以用于指示信号强度

|  |  |  |
|-|-|-|
| LED亮个数 | CSQ范围 | 信号说明 |
| 3 | 24\~31 | 极强（正常通信） |
| 2 | 17\~23 | 强（正常通信） |
| 1 | 13\~16 | 一般（能通信，可能不稳定） |
| 0 | <=12 | 信号差 |
