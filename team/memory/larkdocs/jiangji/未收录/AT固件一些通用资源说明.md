# 三、LED状态指示灯说明

AT固件，只有1个LED可以观察状态，只有在0.125秒的时候，网络才正常。

|  |  |  |
|-|-|-|
| LED | 状态 | 说明 |
|  NET LED | 亮0.2秒，灭1.8秒 | 搜索状态 |
| 亮1.8秒，灭0.2秒 | 待机 |  |
| 亮0.125秒，灭0.125秒 | 激活网络 |  |
