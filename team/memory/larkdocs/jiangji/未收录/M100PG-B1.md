# 简介

YED-M100PG-B1 DTU是由银尔达（yinerda）推出的工业级的单TTL串口DTU 。小巧、稳定、可靠。适合设备控制，状态检测，传感器数据采集等通过4G网络与服务器通讯的场景。

特性如下:

1、5\~12V供电

2、工作环境为-35℃-75℃；

3、支持1路TTL 串口，兼容3.3V电平和5V电平；

4、支持独立定位模块ATGM336H-5NR32(GPS+北斗)或ATGM336H-6N22(单北斗)；

5、支持银尔达DTU透传固件，支持TCP、UDP、MQTT、HTTP、Websocket,阿里云IOT 、腾讯IOT、OneNet，华为IOT，电信云，涂鸦云、ThingsCloud等平台；

6、支持二次开发、支持固件定制。

7、支持SSL证书加密TCPS/MQTTS/HTTPS 协议；

8、支持给用户设备进行固件升级。

## 使用注意事项

如果接MCU，强烈建议硬件设计能控制模组的复位脚或者电源脚，方便异常恢复。



震动、运动环境推荐贴片卡，如果是外置卡有 松动风险，建议打胶固定。



GPS必须放到室外空旷的地方官才能定位，室内无法定位，具体原理可以百度一下。

GPS的数据是WG84坐标，要用到需要转换成使用地图的坐标系，具体方法可以百度自己用的地图的坐标系。



基站定位免费的有频率限制，不支持WIFI定位。如果要求高，建议用付费定位。

基站定位不管是付费还是免费，都可能无法定位，这个是数据库是全面导致的，比如基站信息没再服务器内就无法定位。

# NET LED 状态描述

|  |  |  |
|-|-|-|
| 指示意义 | 现象 | 备注 |
| SIM卡不识别 | NET LED 和RDY/STA LED 5000ms亮 5000ms灭 |  |
| SIM卡正常，但注册不了网络 | NET LED 100ms闪烁,RDY/STA LED 熄灭 |  |
| 注册网络成功，但没连上服务器 | NET LED 500ms慢闪,RDY/STA LED熄灭 | 没有任何通道链接服务器 |

| GPS 定位失败 | GPS LED熄灭 |  |

# 测试硬件连接方法

## 使用YED-M100PG-B专用测试底板测试

电脑安装CH340驱动；电脑USB线接USB TO TTL 接口； LET天线接好；黑色DC座接5\~12V电源；电脑串口软件和测试服务器可以测试设备。
