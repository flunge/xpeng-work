# SIM卡续费和管理方法

> 来源: https://yinerda.yuque.com/yt1fh6/4gdtu/gqv4wlgiht4oeffu  
> 路径: SIM卡续费和管理方法

# 一、特别提醒

SIM卡是4G设备通讯的关键，如果对SIM卡管理不好，售后和维护工作量都特别大，因为SIM卡过期后会销卡，你必须现场更换SIM卡；SIM卡流量预估不准确，会导致SIM卡中途停卡无法通讯。SIM卡续费建议提前1-2个月处理，防止续费不成功问题。

SIM卡销号时间：移动&联通&电信三大运营商卡片，都需停卡后次月23日0:00前续费，如未在规定时间操作，运营商将直接销号处理，无法找回，请及时充值续费，以免影响卡片使用 。



# 二、零散卡续费

微信扫描二维码，输入SIM卡的ICCID即可续费。注意电信卡的ICCID最后一位无效，不用输入，输入后查询不到。如果输入后查询不到，先确认一下ICCID是否正确，确定无误，找销售查询一下卡是否是银尔达的。ICCID可以在卡的背面，20/19位数字编码或者在DTU WEB平台获取。 续费完成后，10-15分钟卡片会自动恢复，后台网络状态1-2小时内同步 。

公众号SIM卡续费多年问题:卡供应商平台限制，不能一次续费多年，如更需要续费多年，需要提供ICCID卡号，单独线下找供应商处理，然后在续费！

# 三、大批量卡续费

提供ICCID表格，找销售线下续费，记得提前1-2个月处理。

如果用DTU WEB平台，SIM卡管理，SIM卡列表，按需求查询到期时间，点击查询，然后点击导出，最后在导出记录里面下载ICCID表格。导出输入的密码是账号密码。



# 四、SIM卡的记录方法

如图使用的是DTU WEB平台配置，平台可以记录SIM卡 ICCID，方便你记录卡。

如果使用的是AT固件或者串口配置或者自己二次开发，需要自己设计系统记录SIM卡ICCID，很多客户忽略记录SIM卡信息，导致设备出去后，无法给SIM卡续费，产生巨大管理风险问题。可以用命令读取后存到生产系统，也可以通过网络把信息传导服务器保存。

DTU 透传固件客户，建议使用DTU WEB配置平台配置参数。

# 五、SIM卡的管理平台

如果购买的DTU固件，并且用DTU WEB平台配置参数，可以直接在DTU WEB平台管理。

如果是没使用 DTU WEB平台，或者想要获取更多的SIM卡信息，或者需要用自己的服务器对接SIM卡API实现自己平台管理。在购买设备或者SIM卡的时候，先找销售创建SIM卡管理账号，让销售把SIM卡分配到管理账号里面，方便管理。注意一定是购买的时候就要处理，否则有可能销售无法记录你购买的全部卡，导致一部分遗漏。

分配后，可以去SIM卡后台核对一下卡数量，防止遗漏。

# 六、银尔达SIM卡的基本说明

1、30M/月的的SIM卡，都不限区域的普通卡，可以连接任意的服务器和大陆任意地方使用。

2、30M/月的SIM卡和360M/12月的SIM卡，每个月限流最高100M，如果超过100M卡会停机下个月恢复，超过100M后即使升级套餐也没用，所以需要提前预流量使用。比如，360M/年的卡，在1月5号之前就用101M，虽然还剩259M，但是由于单月超过100M，1月份就用不了,只能2月份自动恢复。中途如果要用就必须换卡。

3、由于管控原因，SIM卡最好不要在边境使用，建议在当地购买SIM卡，如果必须用，一定需要预留设备的安装位置，安装信息，现场安装图片，防止运营商查检查到异常后，提交证据，证明你的SIM卡是合法使用。

4、由于管控原因，SIM卡都是一卡一机，SIM卡不能更换设备，否则会锁卡，导致网络异常，可以联系销售找运营商解绑，这个过程需要时间，所以轻易不要尝试卡换设备。

5、SIM续费，SIM卡套餐升级，SIM卡管理账号开通/API获取 都可以找销售获取，请联系对应的销售处理即可。

6、再次重点强调，SIM很重要，提前1-2个月续费，不要在快到期的月底去续费，运营商SIM卡众多有可能月底会提前关闭SIM卡，导致网络异常。

# 七、银尔达国际卡说明

银尔达有提供国际卡。可以实现全球漫游通讯，或者在大陆生产测试，在某个其他地区使用卡(包括港澳台等)。详情咨询销售。

国际卡支持亚洲区，欧美区、非洲和南美区，还有全球卡 4种卡。支持国内生产测试然后国外正式使用。

国际卡需要提前设置正确的APN才能使用。



# 八、SIM单独的管理平台

SIM卡有单独的WEB管理平台,[http://sim.yinerda.com](http://sim.yinerda.com)。购买设备的时候找销售分配SIM卡账号和密码，然后把SIM卡分配到账号即可。

SIM卡提供API接口，可以服务器调用API，在自己服务器管理SIM卡，比如查询SIM卡的状态，套餐，流量使用情况，API需要有对接的 AppID和AppSecret，需要联系销售单独申请。

API文档:[https://www.simboss.com/www/service/api](https://www.simboss.com/www/service/api)

# 九、SIM卡的3个周期说明

物联网卡的计费期从激活开始，根据所购买的流量套餐确定，  
通常会在套餐失效日期前进行续费以延长使用期限。  
物联网卡的计费机制与普通手机SIM卡类似，但有其特殊之处，  
主要体现在测试期、沉默期和计费期三个阶段，每个阶段都有其特定的计费规则和注意事项。  
以下详细分析物联网卡的计费周期及其相关特点：  
测试期  
定义：测试期是物联网卡激活后的一个试用阶段，通常为30天，  
包含少量免费流量（一般为5M），用于企业测试物联卡的稳定性及与设备的适应性。  
计费规则：测试期内超出赠送流量的部分，将直接进入计费期，按照正常资费计费。  
若未超出，则测试期结束后自动进入沉默期。  
沉默期  
定义：沉默期通常为3-6个月，此期间内物联网卡尚未开始正式计费，  
但若产生流量，则表示激活并开始计费。  
计费规则：如果在沉默期流量产生，则物联网卡开始计费；  
如果沉默期达6个月，系统将自动激活并开始计费。  
计费期  
定义：计费期从物联网卡激活之日起计算，根据购买的流量包确  
定有效使用期限，用户需在到期前进行续费以避免服务中断。  
计费规则：物联网卡的套餐分类有两种，一种是按月套餐，按自然月计费，  
一种是自定义年套餐，按360天进行计费，这2种分类企业为了方便管理，  
费用都是按年一次性收取。  
流量大小  
分类：物联网卡流量可分为大流量（≥1024M）、中流量（150-1024M）、小流量（10-100M），  
不同流量级别对应不同的价格。  
计费：流量大小直接影响物联网卡的定价，用户需选择合适的流量套餐以优化成本。  
综上所述，物联网卡的计费期始于激活时刻，结束于套餐有效期的截止日期。用户应了解各阶段的计费规则，  
合理选择物联网卡的套餐，注意在套餐到期前及时续费，避免因未及时续费而导致的服务中断。同时，在选购物联网卡时，  
用户应充分评估设备的流量需求，选择最合适的流量套餐，以实现成本效益最大化。
