# 简介

YED-S795C DTU是由银尔达（yinerda）推出的工业级的单TTL串口DTU 。小巧、稳定、可靠。适合设备控制，状态检测，传感器数据采集等通过4G网络与服务器通讯的场景，特性如下:

1. 支持直流5\~36V宽电压供电；
2. 支持全球4G+2G频段；
3. 支持标准35mm导轨安装和螺丝孔安装，外壳阻燃材料；
4. 支持接触放电±8KV，空气放电±15KV；
5. 工作环境为-35℃-75℃；
6. 支持1路TTL 串口，兼容3.3V电平和5V电平；
7. 支持本地信号强度指示；
8. 支持1路ADC模拟量，输入检查电压0\~36V；
9. 支持1路数字量输入，触发电压2\~36V；
10. 支持银尔达DTU透传固件，支持TCP、UDP、MQTT、HTTP、阿里云IOT 、腾讯IOT；

**12) 支持标签logo定制服务；**

**13) 支持二次开发定制。**

# LED状态描述

## NET和RDY LED描述

|  |  |  |
|-|-|-|
| 指示意义 | 现象 | 备注 |
| SIM卡不识别 | NET LED 和RDY/STA LED 5000ms亮 5000ms灭 |  |
| SIM卡正常，但注册不了网络 | NET LED 100ms闪烁,RDY/STA LED 熄灭 |  |
| 注册网络成功，但没连上服务器 | NET LED 500ms慢闪,RDY/STA LED熄灭 | 没有任何通道链接服务器 |
| 成功连上服务器 | NET LED 1000ms慢闪,RDY/STA LED常亮 | 至少有一个通道链接服务器成功 |
