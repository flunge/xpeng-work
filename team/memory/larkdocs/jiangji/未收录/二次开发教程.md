二次开发一般是软件开发，基于银尔达成熟的，价格合适的，超高性价比的硬件产品，开发自己特有的业务逻辑，让客户专注于业务也应用，避免繁琐，低效的硬件设计，生产，测试，组装等工作。



# 一、二次开发固件远程升级说明

二次开发，可以利用模组厂家合宙提供的IOT(不是DTU平台)平台，对设备固件进行远程升级，需要把模块的归属转移到客户IOT账里面。

如果没转移，升级的时候会提示远程升级无权限，也无法做基站定位功能 。

4G合宙IOT平台模块转移归属方法，客户提供合宙IOT账号(是手机号)和项目名称(项目列表的名称)，和要转移的模块IMEI，给销售转移，后续批量采购之前，让销售提前转移过去，避免遗漏。

如果转移后，客户在账号里面查询不到或者我们账号没有这个设备。可以提供模块IMEI，联系合宙查询这个IMEI的归属，然后再重新转移。

# 二、二次开发说明

1、银尔达提供的4G设备全部都支持二次开发；

2、固件可以自己开发，也可以委托银尔达收费开发；

3、硬件可以使用标准硬件，也可以定制特殊需求硬件，比如改需求，改外观，改配置，集成其他模块等；

4、如果自己做固件开发，需要有能力才能做二次开发。

5、二次开发银尔达会提供硬件资源描述用于描述硬件使用的GPIO等，不提供原理图，通过资源描述足够用于二次开发，有需要单独找销售获取。

6、二次开发银尔达人力有限，无法对二次开发细节做支持，二次开发需要加模块厂家售后群寻求开发指导。
