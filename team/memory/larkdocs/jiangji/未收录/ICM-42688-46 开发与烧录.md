# ICM-42688 / ICM-42686 IMU — 开发迭代 & 烧录

> 资料：`docs/supplier-manuals/ICM42688/`（官方 datasheet ds-000347、模块规格书.docx、尺寸图）。  
> 原理图：`design/ICM42688/`（SCH42688new.pdf、SCH_Schematic1_old.pdf）。  
> 例程源码：`firmware/reference/ICM42688/`（Arduino .ino + STM32 F1/F4 多份例程 + 官方驱动 + CubeMX 工程）。

## 0. 本项目怎么用它

- 量产用 **ICM-42688-P**(WHO_AM_I=0x47) 或 **ICM-42686-P**(0x44，±32g/±4000°/s 更抗冲击)；调试期 GY-91 也行（忽略磁力计）。
- 接到 **ESP32-S3**，**优先 SPI**（高速、抗干扰），INT1 中断触发读取。
- 固件开机读 WHO_AM_I 自适配 42688/42686/MPU9250。
- ⚠️ AD0 引脚：用 I2C 时**必须接高(0x69)或低(0x68)**，不能悬空（来自 `readme.txt`）。

## 2. 开发迭代（ESP32 路线）

1. **桌面快速验证（Arduino/PlatformIO）**：把 `icm42688.ino` 接到 ESP32-S3（I2C：SDA/SCL + AD0 接地=0x68），串口看 WHO_AM_I=0x47 与加速度/陀螺原始值 → 确认器件真伪与接线。
2. **转 SPI + INT1**：参考 `F4_CubeMx_SPI_TEST/icm42688.c` 与 `STM32F4_HAL_SPI_INT1` 的寄存器配置（PWR_MGMT0、GYRO/ACCEL_CONFIG0、INT_CONFIG、INT_SOURCE），在 ESP32 用 SPI 重写驱动，INT1→GPIO 中断读 FIFO/数据寄存器。
3. **姿态解算**：移植 `IMU.c` 思路或直接用 Madgwick/Fusion（6 轴，不用磁力计）。
4. **腾空检测**：自由落体判 0g，H=g·T²/8（见阶段一方案）。
5. **量产驱动**：开机读 WHO_AM_I 自适配 0x47/0x44；量程拉满（42686 ±32g 抗落地冲击）。

## 3. 烧录方式

ICM42688 本身**无 MCU、不需烧录**（纯 SPI/I2C 从机）。"烧录"指的是承载它的主控：

- **ESP32-S3**（我们的方案）：VSCode + PlatformIO/ESP-IDF 一键 `Upload`（USB），见 `ESP32-dev-framework-flashing.md`。
- STM32 例程（仅参考）：Keil/CubeMX + ST-Link 下载。
