# 简介

G2100C-E核心板是由银尔达（yinerda）推出的工业级的单串口DTU 。小巧、稳定、可靠。适合设备控制，状态检测，传感器数据采集等通过4G网络与服务器通讯的场景。

特性如下:

1. 支持直流5\~36V宽电压供电，支持供电电压采集；
2. 工作环境为-35℃-75℃；
3. 支持外部独立硬件看门狗，不死机；
4. 支持1路TTL串口；
5. 支持独立定位模块ATGM336H-5NR32(GPS+北斗)或ATGM336H-6N22(单北斗)；
6. 支持运动震动检测；
7. 支持银尔达DTU透传固件，支持TCP、UDP、MQTT、HTTP、Websocket,阿里云IOT 、腾讯IOT、OneNet，华为IOT，电信云，涂鸦云、ThingsCloud等平台；
8. 支持标签logo定制服务；
9. 支持二次开发定制。
10. 支持SSL证书加密TCPS/MQTTS/HTTPS 协议；
11. 支持给用户设备进行固件升级。

## 4G 模块功耗参考

### 普通功耗说明

待机电流为 DTU 保持服务器网络连接，不发数据的时候的平均电流；5V 发送数据的电流平均约16ma计算；12V按 10ma 计算；数据发送完成后大约 12 秒后会自动进入低功耗。如果 GPS 运行，叠加 GPS 功耗，参考 GPS 版本功耗。

|-|-|-|-|-|
| 编号 | 供电电压 | 关闭全部 LED | 待机电流(ma) | 备注 |
| 1 | 5V | N | 6\~7ma |  |
| 2 | 5V | Y | 5.5\~6ma |  |
| 3 | 12V | N | 2.3\~3ma |  |
| 4 | 12V | Y | 2.0\~2.2ma |  |

## 使用注意事项

震动、运动环境推荐贴片卡，如果是外置卡有 松动风险，建议打胶固定。

GPS必须放到室外空旷的地方官才能定位，室内无法定位，具体原理可以百度一下。

GPS的数据是WG84坐标，要用到需要转换成使用地图的坐标系，具体方法可以百度自己用的地图的坐标系。



基站定位免费的有频率限制，不支持WIFI定位。如果要求高，建议用付费定位。

基站定位不管是付费还是免费，都可能无法定位，这个是数据库是全面导致的，比如基站信息没再服务器内就无法定位。
