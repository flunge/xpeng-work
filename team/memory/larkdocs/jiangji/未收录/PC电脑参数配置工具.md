# 二、功能介绍

1、支持中文简体，中文繁体语言。

2、支持参数配置。

3、支持参数密码保护。

4、支持串口命令调试。

# 三、配置界面简介

## 3.1、读取参数

点击运行4GDtucfg.exe程序，选择串口号，点击打开，设备设置密码可以直接读取参数，如果设置了密码需要验证密码才能读取。密码是用来保护参数不被非法读取。

默认波特率115200

## 3.5、配置密码

密码是防止被非法读取参数的，建议使用。下载读取或者配置的时候都需要验证密码，如果忘记密码按Reload恢复出厂设置，或者重刷固件。

## 3.6、保存参数

配置参数后，点击保存参数，设备自动重启，参数生效。

# 五、异常排查

首先确认硬件连接是否正常。

设备默认是115200,可以配置成功，如果设置成了其他波特率，比如9600或者2400等，需要注意串口打包超时时间和RS485的参数。太短了会导致数据读取不完全，或者参数配置失败。推荐9600设置打包超时300ms,2400设置打包超时时间560ms。

如果设置了自动轮询功能，或者服务器有主动发数据，会导致读取参数或者配置参数失败，可以重试。

如果都不行了，只能按reload按键7秒恢复出厂设置或者重刷固件试试。
