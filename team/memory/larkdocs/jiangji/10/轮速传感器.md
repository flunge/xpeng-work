# 轮速传感器：选型与防水整合

> 轮速是**速度精度的杀手锏**。作为 ESKF 的一个量测插件接入（观测车体纵向速度）。**要精准速度，轮速是必需项**。

## 一、为什么轮速不可替代

**第一性原理**：起点→终点的直线距离 L 是常数，但"速度 = L/Δt"**不成立**——每人过弯高低不同，实际 3D 里程因人而异、每圈不同。**真实里程只能由轮速给出**：轮子转过角度 × 轮径 = 真实走过距离，与路线高低/起伏无关。这是轮速唯一不可替代的价值。

**实测对照**（BROAD 21 trials，真实姿态 + ESKF + ZUPT + 起终点 2 位置锚点 + RTS，锚点仅给位置）：

| 维度 | 仅 2 位置锚点（无轮速） | 结论 |
|-|-|-|
| 位置 RMSE | 9.32 m | 2 锚点太稀，中间一圈积分漂移约束不住 |
| 速度 RMSE | 0.23 m/s（\~10-20%） | 不足产品级 |
| 姿态·倾角 | 0.91° | VQF 级 |

> 位置锚点的作用是"校正位置漂移和零偏"，**不是提供里程**。要精准速度/里程，轮速负责测里程，锚点负责压位置漂移，两者分工。

## 二、加轮速后的精度阶梯

在完整 BROAD 39 trials 上，用真实 VQF 姿态 + ESKF + ZUPT + 2 位置锚点 + 事件驱动轮速 + 软垂直速度约束 + RTS 平滑实测：

| 配置 | 速度 RMSE | 结论 |
|-|-|-|
| 纯积分 + ZUPT | \~2.2 m/s | ❌ 漂几倍 |
| + RTS 后向平滑 | \~0.42 m/s | ⚠️ 勉强 |
| + 真实 2 位置锚点 | \~0.23 m/s (\~11%) | ⚠️ 不足 |
| + 轮速（事件驱动） | \~0.14 m/s (\~7%) | ✅ |
| + 软垂直速度约束 | **0.112 m/s (\~6%)** | ✅✅ **产品级** |

**杠杆排序**：RTS 平滑 > 事件驱动轮速（测里程）> 位置锚点（压漂移）> 垂直约束。

**两个关键算法优化**（属正确性修复，非调参）：

1. **事件驱动更新**：霍尔脉冲在**发生时刻**触发 update，而非"阶梯保持上一脉冲平均速度"——后者加减速时严重滞后（0.36→0.14 m/s，-61%）。
2. **软垂直速度约束**：泵道起伏但世界系 z 向净速度受限，加宽松软约束（σ≈1 m/s）压垂直漂移。

## 三、选型（免开孔防水 + 装配约束）

**装配约束**：车是外购的，不与车厂合作 → 排除需改花鼓/车厂预装的方案；但**教练调教时可做轻量装配**（套辐条磁环，免焊几分钟一次装好）。传感器一律封在密封盒内，不破坏防水。

| 方案 | 车轮侧 | 谁装 | 分辨率 | 结论 |
|-|-|-|-|-|
| **霍尔锁存 IC + 辐条磁环盘** ⭐ | 多极磁环盘套辐条（扎带固定） | 教练调教装 | 高（每圈数十脉冲） | **首选** |
| 霍尔 IC + 4-6 颗卡扣磁铁 | 辐条卡 4-6 颗 | 教练装 | 中（4-6 脉冲/圈） | 磁环买不到时的退路 |
| 电感数金属辐条（LDC3114） | 无（辐条即齿） | 零安装 | 高 | 备选，童车辐条细隔壳余量小 |
| 单颗卡扣磁铁 | 1 颗 | 教练装 | ❌ 1 脉冲/圈 | 低速测不到，排除 |

**首选霍尔 + 磁环理由**：装配现实可行（不碰花鼓、不需车厂）；高分辨率（磁环多极）；霍尔测速是自行车码表几十年成熟方案；与"不用磁力计"不冲突（霍尔是阈值开关检测局部强磁体，非测地磁，局部磁场远强于地磁/LF）。

## 四、整合设计（全封闭防水）

```
┌──── 密封 ABS 盒（无开口，磁吸/Qi 充电）────┐
│  ESP32-S3 ──GPIO中断←── 霍尔锁存IC        │
│                          ▲ 磁场穿透ABS壳  │
│  IMU / LF / 2.4G         │ (气隙≤5-8mm)  │
└──────────────────────────┼────────────────┘
                           │
   后轮辐条磁环盘 ──────────┘（旋转经过霍尔上方，教练装一次）
```

- **固件**（ISR 只锁脉冲时间戳+计数）：轮速任务算 `脉冲间隔 → 角速度 × 轮径 = 纵向线速度`，作 ESKF 轮速 update；
- **NHC 非完整约束**可同时加：正常骑行车体 y/z 向速度≈0，额外 update 进一步约束（免费收益）；
- **安装位置**：模块放**后下叉靠近后轮**（守"不装前叉"，车架刚体用后轮不影响姿态）。

## 五、封 ABS 壳的三个注意点

**磁场无问题**（ABS 非磁性，磁场无衰减穿透），但需注意：

1. **气隙**（最关键）：霍尔到磁体总距离 = ABS 壁厚(2-3mm) + 安装间隙，控制 **≤5-8mm**；量产用宽气隙余量的锁存 IC（A1220/AH3774）；
2. **去 LED**：不透明壳内 LED 不可见且耗电，量产删；
3. **电平**：现成模块 5V 输出 → ESP32 3.3V GPIO 需分压，或用 3.3V 供电的裸 IC。

## 六、与 125kHz LF 唤醒的电磁共存

**几乎不串扰**：

- **频段隔离**：LF 是 125kHz 交变场，霍尔是低带宽器件（DC\~低 kHz）+ 磁环是静磁场，125kHz 远超霍尔带宽被内部滤除；磁环不辐射 125kHz，不干扰 LF 接收；
- **LF 是唤醒式**（仅过线几十 ms 发场，非持续），绝大部分时间不存在；
- **唤醒瞬态处理**：霍尔走线远离 LF 线圈 + 地平面隔离 + VCC 就近去耦 + 输出 RC 去抖 + 可选固件屏蔽窗（LF 唤醒后 \~50ms 内轮速去抖，且此时轮速由锚点接管，无害）。

## 七、原型与量产

- **原型**：现成 A3144 霍尔模块 + 卡扣磁铁直接可用（5V→3.3V 分压），跑通"脉冲→轮速→ESKF 融合"闭环；
- **量产**：霍尔锁存 IC（A1220/AH3774）封 ABS 盒内（去 LED、3.3V 供电）+ 教练装辐条磁环盘；
- **RFQ 待确认**：辐条直径/可装磁环半径、后下叉到辐条气隙（含壁厚）、霍尔工作气隙 vs 磁体磁通、每圈磁极数 vs 最高速最小脉冲间隔。

## 八、现状与板卡口径（2026-07 同步）

- **tag-2.0 车载板：**保留轮速霍尔接口（J4+R14，IO6），本方案按此落地。
- **tag-3.0（Vehicle Tag + UWB）：**按规格移除轮速霍尔（板面/pin 让给 DWM3000 UWB）。ESKF 的轮速量测插件在 estimator 中保留，接口不动；若 tag-3.0 后续需要产品级速度精度，可经扩展口加回轮速传感器。
- **手环（阶段四）：**贴身人体件、与车轮无关，不含轮速，与本方案无冲突。
