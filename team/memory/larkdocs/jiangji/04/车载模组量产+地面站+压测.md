## 二、车载模组（自研 PCB 产品化）

**硬件**：ESP32-S3 模组 + **Si3933（LF 唤醒）** + 6 轴 IMU（ICM-42688，量产级）+ 锂电 + 充电管理(TP4056/磁吸) + 电量计 + **电源开关** + **电量 LED** + 2.4G 板载天线。

- **结构**：**ABS 防水盒定制（IP67）+ 公司 logo**；前叉/中架安装（车架夹/绑带）；**开关 + 充电/电量展示接口**（充电优先**磁吸触点**，防水无开口；电量用 LED 显示）。
- **天线**：塑料壳内置 2.4G + LF 唤醒线圈，远离金属/电池。
- **PCB**：一次预留 IMU/Si3933/4G/UWB 焊位（为阶段四/五留口）；ESP32-S3 部分照乐鑫开源原理图，传感器照各 datasheet 参考电路。

## 二·五、功耗预算与电池选型

> 目的：定电池容量 + 续航目标 + 必做的低功耗优化。数字为工程估算，**上板实测回填**。

### 各部件电流（3.3V 域，典型）

| 部件 | 状态 | 电流 |
|-|-|-|
| ESP32-S3 @240MHz 双核 | 跑 ESKF | \~40-50 mA |
| 八线 PSRAM(OCT) | 常开 | \~20-30 mA（量产该关，大户） |
| 2.4G 发射(ESP-NOW/BLE) | 瞬时峰值 | 200-350 mA（均值看占空比） |
| ICM-42688 IMU | 1kHz | \~1 mA |
| BMP280 气压 | 25Hz | \~0.5 mA |
| Si3933 LF | Scan 待机 | \~10-20 µA |
| LDO/板损 | — | \~5-10 mA |

### 两档功耗

- **档A 当前调试配置（240MHz + PSRAM + BLE 常开）**：平均 \~90-130mA，取 **110mA**。
- **档B 量产优化后（160MHz + 关 PSRAM + 骑行关 BLE + IMU 200Hz）**：平均 \~40-60mA，取 **50mA**。

### 续航（容量 ×0.8 ÷ 平均电流）

| 电池 | 档A(110mA) | 档B(50mA) |
|-|-|-|
| 300mAh | \~2.2h | \~4.8h |
| **500mAh** | \~3.6h | **\~8h** |
| 1000mAh | \~7.3h | \~16h |

### 结论

- **推荐 500mAh LiPo + 量产低功耗优化 → 工作态 \~8 小时**（覆盖一天训练），晚上磁吸充电。
- **低功耗优化是必做项**（否则 500mAh 只 3.6h）。四条最有效（按收益）：

  1. **关八线 PSRAM**（省 20-30mA，ESKF 不需外部 RAM）——单条最划算；
  2. **骑行时关 BLE**（只留 ESP-NOW，BLE 仅标定/看数据时开）；
  3. **主频 240→160MHz**；
  4. **IMU 1kHz→200Hz + 不骑深睡靠 Si3933 LF 唤醒**（待机 µA 级）。
- ⚠️ **2.4G 发射峰值 200-350mA**：PCB 电源要留**大电容**扛发射瞬间，否则掉电重启（与调试期"面包板供电连不上 BLE"同一物理问题）。

## 三、地面站定制（起点 + 终点）

**方案优先级**：

1. **走通中科微(CSM)方案**：CSM 激励器（确认能连续发射+窄触发区）+ **定制地感线圈（薄、无凸起、覆盖 2m 宽）+ 我方 ESP32 收 2.4G 上云。若 CSM 能定制贴地薄线圈→首选**。
2. **若 CSM 走不通**（线圈/连续发射不满足）：另寻其他 125kHz LF 激励器/地感线圈厂商定制（激励器 + 定制地感线圈，标签/读卡器不用，2.4G 用我方 ESP32）。
3. 地感线圈**防水防压无凸起**：埋设齐平 或 超薄薄垫+斜边（见 `../docs/_archive/project-research-assessment.md` 附录）。

**地面站 BOM（单套）**：激励器(¥160-400) + 定制地感线圈(询价) + ESP32-S3 接收(¥25) + 供电(电池/适配器) + IP67 外壳/支架 ≈ **¥300-700/套**；2 套 ≈ ¥0.6-1.4 万 + 线圈 NRE。

## 四、软件 / 云端（产品化）

- 固件：阶段一固件**强化**——OTA 升级、低功耗(按需唤醒/休眠)、电量上报、断网缓存补传、出厂标定(IMU 零偏/安装对齐)。

## 七、风险

- 地面站定制周期长（线圈/连续发射）→ 早确认 CSM 能否做，不行尽早另寻他厂。
- ABS 盒开模 100 套量小、摊销高 → 简模/3D 打印 + 丝印 logo 降一次性投入。
- 多车并发拥塞 → 边缘解算只发状态量、错峰、必要时多接收点/分信道。
- 认证(SRRC)是量产关键路径 → 提前启动。
