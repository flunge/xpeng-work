# 小程序 App 设计（阶段二 · 设备交互 / 计时系统 / 专利方向）

> 量产阶段小程序要做的**与硬件设备交互部分：设备绑定/签到、【我的设备】、成绩/排行/回放。已有雏形在【我的设备】。后续按此申请专利**：LF 唤醒计时 + 边缘姿态解算 + 无线标定 + 云端漂移免疫分析的整套人机交互闭环。  
> 三端基础运营功能见 `../phase1-debug/app.md`。BLE 协议见 `../app-ble-protocol.md`。

---

## 一、设备生命周期

- **绑定**：扫码→登录→购买(`purchaseDevice`)→adminKey 激活(`activateDevice`)→BLE 写 `owner_token`(`CMD_BIND`)→首次标定落 NVS。详见 `solution.md` §1。
- **签到**：过 LF 起点门自动签到（主）/ BLE 邻近（辅）/ 扫码（兜底）。

## 二、【我的设备】页面（现状 + 规划）

| 子模块 | 内容 | 状态 |
|-|-|-|
| 设备连接 | 搜索→自动连接；连上显示设备信息 + 断开；**实时挂载传感器**（IMU/气压/LF 在位/失效） | 已实现 |
| 姿态系统 | 陀螺标定(静置≥10s落盘) / 加计六面(引导+放置检测) / 实时姿态(地平仪+录制) / 文件管理(上传云端/删除) | 已实现 |
| 触发系统 | 激励器 ID + 红绿灯 + RSSI 时间曲线（合成+平滑，过线取最近） | 已实现 |
| 成绩/回放 | 圈速、姿态回放、雷达图（速度/过弯/泵压/跳跃/稳定） | 待开发 |
| 排行榜/社交 | 场馆榜、好友对比、成就徽章 | 待开发 |

## 三、BLE 交互协议

App↔Tag 的 GATT 协议（标定/绑定/姿态流/触发调试/FS/OTA）详见 `../app-ble-protocol.md`（`proto_ver` 与固件 `ble_calib_proto.h` 一一对应）。前端封装在 `cycling/package/miniprogram/utils/ble-calib.js`。

## 四、数据展示原则（配合云端分析）

- **骑行中**：实时圈速大字 + 与个人最佳差值；简易姿态。
- **训练后**：session 汇总（圈数/最佳/平均）+ 每圈明细 + 高光。
- **长期**：成长趋势、训练量、稳定性。
- 面向学员/家长用**大白话 + 鼓励**（LLM 生成），教练用**专业指标**。分析方法见 `cloud-ai-analysis.md`。

## 五、专利方向（申请前梳理）

整套"过线 LF 唤醒 → Tag 微秒计时 + 边缘姿态解算 → BLE 无线标定 → 云端漂移免疫特征分析 → 三端差异化展示"的人机交互与数据处理闭环，作为专利保护范围。细节待专利代理对接时补。
