# 调试采购清单 — 二期（腕表健康 + 安全 + 高光视频 + 云端能力）

> 用途：**二期**物料——在一期（车载计时+骑行数据，见 `调试采购清单-一期车载形态.md`）基础上叠加：① 腕表贴身健康 ② 安全（冲击）③ 高光视频链路 ④ 云端 AI 能力。

## 清单四 ▸ 云端能力（腾讯云，服务非硬件）

| 能力 | 腾讯云产品 | 用途 |
|-|-|-|
| 对象存储 | **COS** | 短片、热力图、原始/odom 数据 |
| 无服务器计算 | **云函数 SCF** | 数据到→触发分析/路由/圈速 |
| 弹性算力 | **CVM / GPU 云服务器 / TI-ONE** | 轨迹重建、热力图、CV、模型推理 |
| 大模型 | **混元大模型 / TI 平台**（或其它 LLM API） | AI 教练自然语言点评 |
| 视频（可选） | **云点播 VOD / 媒体处理 MPS** | 短片转码/分发/AI 标签 |
| 数据库 | TencentDB（MySQL/TDSQL） | 用户/绑定/成绩/telemetry/视频记录 |
| 推送 | MQTT / 微信订阅消息 | 实时/按圈推送小程序 |

> **AI 分析放云端（数据本就在腾讯云、要历史对比+LLM）；视频处理放边缘盒**（大流量、省带宽）。详见报告附录 C.4。

## 采购建议

- **每骑手件**（清单一/二/五）随腕表/车载量产；验证期先买 1-2 套模块插线跑通（不含清单五封装件）。
- **每场地件**（清单三）一套即可覆盖一个场地；先上 1 台 IP 相机 + 1 台边缘盒跑通"连续录→时间戳裁片→上云→小程序"最小闭环。
- **云端**（清单四）按量开通，日活百人内成本低；AI/GPU 按需启用。
