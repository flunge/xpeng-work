# 项目总览与导航 · 星际骑遇智能计时系统

<callout emoji="💡">
泵道青少儿骑行 **计时 + 运动数据 + 视频 + 发力分析** 系统。本文是全项目入口：五阶段路线 + 技术主线 + 全文档导航。

## 一、五阶段路线图

| 阶段 | 目标 | 状态 |
|-|-|-|
| **一 调试验证** | 链路走通（模组+固件+云+小程序），不求量产 | 🎯 主攻 |
| **1.5 无源计时** | 只做精准计时：无源 RFID(认人)+光电门(定时刻)，全算在基站 | 🆕 并存旁路 |

| 四 手环模组 | 手环(6轴IMU+人体数据)，与车端并存做发力分析 | 待启动 |
| 五 UWB+视觉 | 相机+UWB 全场建模/定位+ReID+骨骼点（UWB 选型/可行性预研已前移到阶段三，见下方导航） | 远期 |

## 二、技术主线

- **计时**：过线微秒时间戳（主线标签端锁存 / 无源路线基站光电锁存）；起点+终点两点位
- **数据**：标签边缘解算（VQF 姿态+腾空+速度），只传状态量不传原始 IMU
- **上行**：ESP-NOW（标签→基站）→ 基站 4G 上云，按圈准实时
- **云端**：微信云运营 + 量产计时数据云（认人路由 + AI 分析）
- **展示**：三端小程序（用户/教练/管理员）
