# 阶段一 · 小程序（三端基础功能）

> 微信小程序原生 + 微信云开发，用户/教练/管理员三端。阶段一为运营数字化基础功能（已实现），设备交互/成绩展示是量产内容。

## 一、技术栈与结构

- **框架**：微信小程序原生（基础库 3.15.2+）+ 微信云开发；
- **主题**：主色黄 `#FFC928` / 红（选中）`#F2554A`；单位 rpx（750 设计稿）；颜色走主题 CSS 变量；
- **云函数调用**：统一封装层，按事件类型路由。

## 二、三端基础功能（已实现）

**用户端**：

- 首页（城市定位 + Banner + 门店 + 教练 + 打榜）；
- 预约（周日历 + 筛选 + 课程列表 + 等位）；
- 训练（已约/已完结/补课 + 直播 + 课评 + 请假）；
- 我的（课卡 + 合同 + 多孩管理 + 订单 + 设置 + 资料）。

**教练端**（子包）：课程 CRUD、我的等。

**管理员端**（子包）：后台管理。

## 三、交付前静态校验（硬约束）

任何前端改动交付前必须跑：

1. WXML/WXSS/JSON 校验（标签闭合、绑定与大括号配平、JSON 合法）；
2. 改动的 JS 跑语法检查；
3. 改数据跑数据库构建脚本，看外键 + 一致性通过。

不允许把标签未闭合 / `{{ }}` 不配平 / JSON 非法这类低级错误流给用户。

## 四、数据—显示—逻辑闭环（核心约束）

- 每条数据都要被消费（有展示或参与计算的页面）；
- 每个显示元素都要有真实数据支撑（不造占位/假数据）；
- 同一份数据在三端口径一致；每个业务动作把连锁状态变化全部落实。
