# 阶段 1.5 · 无源计时快速通道 · 方案总览

<callout emoji="💡">
在有源标签主线之外新增的**并行旁路**，只为最快拿到"精准过线计时"这一个功能。标签用**无源 RFID 标签**（不带电），身份识别 + 时间计算 + 上云 + 下发**全在基站**。与主线并存，不替换。

## 二、和主线的区别

| 维度 | 主线（有源标签） | 快速通道（无源） |
|-|-|-|
| 标签 | ESP32+IMU+电池，要充电/OTA | **无源 UHF 标签**，无电、免维护、¥1-5/张 |
| 时间戳在哪 | 标签端 LF 中断锁存 | **基站端**光电边沿锁存 |
| 身份识别 | 标签自带 ID | **基站 RFID 读到 EPC** |
| 能力 | 计时+姿态+腾空+速度 | **只有精准计时**（无运动数据） |
| 落地速度 | 慢（固件/标定/防水/续航都要做） | **快**（无源标签即贴即用） |

**一句话**：用"无源标签认人 + 光电定时刻 + 基站算一切"换取最短上线时间，代价是没有运动数据（那是主线的事）。两者不互斥，可同场地并存。

## 三、三源融合逻辑

| 器件 | 回答什么 | 角色 |
|-|-|-|
| 光电对射/反射 | 何时过线 | 权威时刻（微秒边沿，<5ms） |
| UHF RFID | 是谁 + 在不在场 | 身份（EPC）+ 在场门控 |
| RSSI | 是不是正靠近 | 一致性校验，剔误触 |

**关联状态机**（单列下零歧义）：车进读区→读到 EPC 标记在场 → RSSI 上升 → 光电遮断锁微秒戳 t → 关联"在场且 RSSI 最高"的唯一 EPC = 过线者 → 300ms 去抖 → 车离场清标记。

## 四、落地步骤与验收

桌面单点(光电锁戳)→加 RFID(读 EPC)→关联逻辑+去抖→4G 上云→App 绑定→两断面验圈速→现场防水安装。

**验收**：可靠触发(提速不漏不误触)；微秒时刻+正确 EPC，圈速=终点−起点；三源关联单列零错配；端到端有数据；小程序秒级显示；防水箱经受灰尘/淋水。
