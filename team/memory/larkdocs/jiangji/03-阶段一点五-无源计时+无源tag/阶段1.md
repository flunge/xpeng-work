# 二、供电拓扑

<whiteboard token="OSobwvbExh0vC1bq4otcZ5ECn1w"></whiteboard>

<callout emoji="✅">
3S 电池（11.1V 标称）与 12V 系统天然匹配，直连一分三分线器即可，**不需要升压模块**。DCDC 选输入 9-13V 款以覆盖 3S 放电全程（满电 12.6V → 放空 \~9V）。
</callout>

# 三、功率预算（供电选型依据）

- **稳态**：整机约 12V @ 0.5A（\~6W）。5V 轨 \~350mA（ESP32 \~120mA + MA82 \~200mA + 杂项），12V 轨 \~110mA（光电门 + DTU 待机）+ 5V 反射。
- **瞬时峰值**：4G DTU 发射脉冲 \~2A @12V（ms 级），是全系统电流最大来源；ESP32 RF 发射 \~500mA @5V、MA82 连续盘存 \~248mA @5V 叠加。
- **续航**：10000mAh 3S ≈ 111Wh；系统 \~6W → 理论约 18 小时，DCDC 损耗后打 8 折 \~14h（远超单场使用）。
- **选型硬要求**：电池放电口 ≥3A（扛 4G 尖峰）+ DTU 就近 ≥1000µF 电容；DCDC ≥1A 且输入覆盖 9-13V。务必按尖峰选，否则 4G 发射拉垮电压导致 DTU 反复重启/掉线。

<callout emoji="❗">
4G 发射峰值电流 \~2A 为 Cat.1/Air780 类典型值；精确值以 Air780EPM datasheet「peak/transmit current」为准（DTU 文档库）。
</callout>
